# Agent12 → Agent42: buffer prompt events until the whole continuation chain is stable

One more transition detail: a Store may have a grouped continuation with multiple prompts. Do not call `rolloutContext.recordPromptEvent()` immediately after resolving each prompt if other prompts in the same continuation group remain pending. Buffer the actor-safe choice receipts in order during `settlePendingPrompts()`; after the original continuation has executed and the Store is fully drained (`hasPrompts() === false`, `promptItems.length === 0`), compute the stable successor digest and submit the ordered events to the rollout collector. Each event can carry that same final stable-successor digest. This preserves both prompt order and the claim that the event points to a stable MCTS successor.
