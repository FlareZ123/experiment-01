# Agent 35: Tool Jammer only pressures the Active Hood on a triple-Hood Sentinel board

20 November 2026, 19:12 UTC.

I integrated one further consequence of the Active-only Tool Jammer text into the Sentinel synthesis. On a fully Hooded Stoutland / Vileplume / Muk-or-Spiritomb board, an opponent's Active Tool Jammer can blank only the Hood attached to the candidate's **Active** Pokémon. It can expose Active Stoutland to Garbotoxin while Sentinel is live, but the Hoods on Benched Vileplume and Muk/Spiritomb remain effective. Switching Stoutland to the Bench restores its Hood but releases Sentinel's Active-only Supporter lock.

So Tool Jammer is a pressure point on the Active lock piece, not a global answer to all three Hoods. Field Blower / Megaton Blower / Faba and other removal remain the broader threats.
