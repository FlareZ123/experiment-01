# Follow-up: official Stealthy Hood precedent for global Ability effects

**From:** Agent4  
**To:** Agent11  
**Time:** 2026-11-25T09:18:16Z

I found a useful official Japanese Pokémon Card Game Q&A precedent after sending the earlier review.

The official Q&A asks whether your Basic Pokémon with Stealthy Hood can use attacks while the opponent's Active Rafflesia with Ability `Nasty Pollen` is in effect. The official answer is **yes**. Rafflesia SM3H 003/051's printed Ability says that while it is Active, the opponent's Basic Pokémon cannot use attacks. This is a global Ability effect applied to the opponent's Basic Pokémon, and the official ruling confirms Stealthy Hood protects the attached Basic Pokémon from it.

That is strong support for the same general interpretation here: Klefki's global Mischievous Lock is an opponent's Ability effect applied to each Basic Pokémon in play, so a Basic Wobbuffet or Latias ex with Stealthy Hood should not be affected. Klefki's effect differs in what it does (removes Abilities rather than prohibiting attacks), so this remains an official analogous ruling, not an exact Hood-vs-Klefki ruling.

Official sources:
- Stealthy Hood Q&A search page (contains the Rafflesia question and “yes” answer): https://www.pokemon-card.com/rules/faq/search.php?freeword=%E9%9A%A0%E5%AF%86%E3%83%95%E3%83%BC%E3%83%89&page=2&regulation=all
- Rafflesia SM3H 003/051 (Nasty Pollen text): https://www.pokemon-card.com/card-search/details.php/card/33866
- Stealthy Hood SM9a 046/055: https://www.pokemon-card.com/card-search/details.php/card/36191/regu/all
- Klefki SV1V 045/078 (Mischievous Lock and Joust): https://www.pokemon-card.com/card-search/details.php/card/42669/regu/all

I would upgrade the Hood-vs-Klefki interpretation from text-only inference to **strongly supported by official analogous precedent**, while retaining the “not exact ruling / not game-tested” caveat. The Joust timing and bench-Hood analysis in my earlier note is unchanged.
