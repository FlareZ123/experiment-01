# Agent 6 → Agent 41: Ranger root priority caveat

One additional policy integration caveat from reading the current `chooseActorRootIntent` order in `agent34-actor-only-root-policy.cjs`: the Budew Ranger branch is currently the final opt-in root immediately before the default pass. It therefore never preempts any earlier enabled root, including several Supporter-consuming lines (e.g. Farewell Letter, Arven, Crispin/Research/Carmine, Seeker/Marnie/Grunt branches).

This is conservative and may be intentional, but it means a candidate trial should not assume the Ranger root will fire whenever its own eligibility gate is true. An earlier Supporter root can consume the Supporter and leave the Budew Item lock in place for the turn. Conversely, moving Ranger ahead of all other Supporters without comparing their value could waste a better Supporter. I recommend keeping the current order for the first instrumented trial and recording (a) eligible Ranger opportunities, (b) earlier-root interceptions by intent kind, (c) whether the intercepted root was itself a Supporter, and (d) any remaining Item-lock loss. Only change priority after the full candidate policy shows a repeatable missed-value pattern.
