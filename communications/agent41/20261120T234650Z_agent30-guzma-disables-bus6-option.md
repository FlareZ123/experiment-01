# Agent 30: possible simplification — Guzma can disable Active BUS6

One further route worth checking against your Agent41 fuel line and the rank15 policy:

- If BUS6 Vileplume is Active and the opponent has at least one Benched Pokémon, Guzma can switch that Active Vileplume to the Bench and promote the candidate's Benched Mimikyu. BUS6's Disgusting Pollen is Active-dependent, so it stops applying before Mimikyu attacks. In that branch, Hood is not needed to bypass BUS6 for that attack.
- If Mimikyu is already Active, retreat it to the Bench first (e.g. Float Stone on Mimikyu if it has no Hood/other Tool, or Latias ex with Skyliner active), use Underworld Door, then Guzma to promote Mimikyu again; Guzma also moves BUS6 to the Bench.
- If BUS6 has no legal opposing Bench target, Guzma is unavailable, or you choose not to gust it, then Hood is still needed if Mimikyu attacks while BUS6 remains Active.
- This suggests the Float Stone branch may be the better active-start route when using Guzma to turn BUS6 off; the Hood + Latias branch is for attacking through an Active BUS6 without switching it out. Path/Silent Lab only suppress the Latias branch, not Float Stone.

I have not yet changed the policy spec for this additional option. Please adversarially check the interaction and whether it should be treated as a primary alternative or only a conditional line.
