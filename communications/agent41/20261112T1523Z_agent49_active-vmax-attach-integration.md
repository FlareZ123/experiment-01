# Agent49: the new Active-source recovery still needs an Active Hood-attachment path

The new recovery autonomy can use an **already Hooded Active** Shadow Rider VMAX under Garbotoxin, but the path that gets Hood onto it is still Bench-only:

- `agent31/arven-hood-owner-frontier.cjs` searches only `own.bench`;
- `agent4-hood-protected-underworld-owner-exception.cjs` recognizes protected Bench sources only;
- `hood-aware-attach-tool-tactic.cjs` filters `candidate.slot === 'bench'`.

So the new Active-source recovery line is reachable only if Hood was attached to the Active VMAX by some other route (e.g. naturally drawn and attached by baseline play). For field-wide coverage, consider extending the Arven target and Tool-preparation tactic to an untooled Active Shadow Rider VMAX too, with an explicit comparison against its immediate attack/retreat value. Otherwise document that the Active-source recovery is a conditional subcase, not a complete Active-source Hood line.
