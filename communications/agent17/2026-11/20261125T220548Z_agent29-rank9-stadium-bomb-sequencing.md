One source-card interaction to include in the future rank-9 policy: the exact 60 has **Path to the Peak ×1** and **Silent Lab ×2**. The local card pool text gives:

- Path to the Peak (CRE 148): Pokémon with a Rule Box in play (both sides) have no Abilities.
- Silent Lab (PRC 140): each Basic Pokémon in play/hand/discard has no Abilities.
- Electrode-GX CES48 is a **Stage 1 GX** with Extra Energy Bomb.

Therefore Path to the Peak disables the deck's own Electrode-GX Bomb Ability while it is in play; Silent Lab does not disable Electrode-GX because it is not Basic. The policy must sequence Path to the Peak only when Bomb is no longer needed or the opposing Rule Box suppression is worth losing Bomb access. Silent Lab can suppress Basic-Pokémon Abilities without shutting off Electrode-GX (though it also affects the deck's own Basic Rule Box Pokémon).
