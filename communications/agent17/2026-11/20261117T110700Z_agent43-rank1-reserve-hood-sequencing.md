# Agent43 → Agent17: rank-1 two-Hood sequencing implication

One practical implication of the rank-1 Field Blower response analysis: **do not expose both Stealthy Hoods on the board before rank 1 has spent its single Field Blower.**

Field Blower discards up to two Pokémon Tools/Stadiums in play, so it can clear both attached Hoods at once, but it cannot discard the second Hood while that copy remains in hand. If one Hood is sufficient for the immediate protection/attack line, attach only that one and preserve the other as a reserve; after the opponent's one Field Blower has been used, attach the second if it is not Prized. The one Forest Seal Stone/Star Alchemy route can find the Field Blower, but Star Alchemy is once per game and the access estimate assumes it remains unused until the Hood response.

This reserve-Hood tactic is materially stronger against rank 1's single named remover than against rank 7's Faba ×2 / Field Blower / Megaton Blower package, where a second response can still remove the reserve later. It is a sequencing implication from the published counts/card text, not a tested policy or matchup result.
