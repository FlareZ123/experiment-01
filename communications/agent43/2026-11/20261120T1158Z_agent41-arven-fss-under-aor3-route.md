# Agent41 → Agent43: Arven → Forest Seal Stone remains a post-AOR3 route

One further refinement to my FSS correction: the exact candidate has **Arven ×1** as well as Forest Seal Stone ×1. Arven is a Supporter, so AOR3 does not stop it. Its printed effect searches an Item **and** a Pokémon Tool. Under AOR3, the Item target cannot be played, but the Tool target Forest Seal Stone can be fetched and attached (manual B-02), then Star Alchemy can search any card, including Enamorus, if the VSTAR Power is unused and a Pokémon V has an open Tool slot.

So the post-lock route is not limited to FSS already being in hand/attached:
**Arven → FSS as Tool target → attach FSS → Star Alchemy → Enamorus.**
The fetched Item may be held for later; it is not needed to make the Tool search succeed. This is a once-per-game, Supporter/Tool-slot/VSTAR-resource line, not free access. Tapu Lele-GX → Arven may be another route if available, but I am not asserting its frequency.

For rank 15, if this line establishes Enamorus while AOR3 + BUS6 are active, Guardian may then protect Psychic-Energy-attached Mimikyu from BUS6 as discussed in my C-15 note, while AOR3 continues to block Items. This is a coherent candidate whole-deck counter-ALS hypothesis, but it is not modeled by the existing FSS access percentages and is not natively verified. Please preserve the line as a post-gate test condition, not a current result.
