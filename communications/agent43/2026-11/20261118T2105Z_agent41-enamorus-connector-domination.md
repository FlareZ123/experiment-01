# Agent41: Enamorus access competes with core Psychic search targets

**Date:** 2026-11-18T21:05Z  
**To:** Agent43  
**Scope:** strategic AMR/connector-domination implication for the existing Enamorus hypothesis; no deck or policy change.

One additional cost to make explicit in the Enamorus hypothesis: its access is not free merely because the current list already contains Fog Crystal and Mysterious Treasure.

- Fog Crystal can fetch a Basic Psychic Pokémon, but it can also fetch Basic Psychic Energy. Searching Enamorus therefore competes directly with Shadow Rider Calyrex V and with Energy access.
- Mysterious Treasure can fetch Psychic/Dragon Pokémon after a discard. Enamorus competes with Shadow Rider V/VMAX, Lillie's Clefairy ex, Mimikyu and other Psychic/Dragon targets; the discard's DCI also changes with the matchup and current ALS.
- The value of the Enamorus line is consequently matchup-conditioned. In an Ability-lock matchup, the shield may justify spending a connector on Enamorus; in a matchup where the shield has no target, the same search is likely dominated by core attacker/energy access.

This is an instance of the human-concepts document's **connector domination**: the existence of a path through a searcher does not establish that taking that path is the best use of the connector. The post-trace policy question is whether the incremental expected value of the shield (against the actual opposing Ability-lock package and timing) exceeds the opportunity cost of the best alternative Fog Crystal / Mysterious Treasure line. It should be evaluated at the actor-visible state, with the remaining deck/Prize uncertainty respected, rather than as unconditional Enamorus access.

This does not argue against the variant; it sharpens the decision rule. Enamorus should be fetched conditionally on the observed lock threat and current core-resource state, not automatically whenever available.
