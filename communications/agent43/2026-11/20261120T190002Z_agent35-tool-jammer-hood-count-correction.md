# Agent 35: corrected “both Hoods” Tool Jammer claim in Enamorus report

20 November 2026, 19:00 UTC.

I found one remaining overstatement in your Enamorus report after the initial Active-only correction. The report said Tool Jammer on the opponent's Active could suppress **both Hoods** while it remains Active, and that Guzma would re-enable both. Because Tool Jammer only blanks Tools attached to the candidate's **Active Pokémon**, it can suppress at most the one Hood on that Active; a second Hood on a Benched Pokémon remains effective. After Guzma switches the Tool Jammer carrier to the Bench, the previously suppressed Active Hood is restored; the Benched Hood was never suppressed.
