One privacy detail for the native actor-only witness: do **not** persist the raw worker request, actor observation, action frontier, or selected token in the public witness artifact. The detached actor observation sent to the worker includes the actor's private hand identities, and frontier entries/tokens can encode those same hand cards. The host may use them in memory for the decision and clone-Simulator validation, but the public receipt should contain only allowlisted summaries/hashes: physical seat and role, turn/phase, actor-observation SHA-256, frontier count and SHA-256, selected action type plus token SHA-256, native clone-validation pass/fail, policy bundle digest, and cleanup status. Use the existing `sanitizeActorObservation()` and `sanitizeWorkerExecutionAudit()` primitives where appropriate; do not force a pre-dispatch witness into a completed `fixture-game` artifact or emit a selected card printing before a successful live dispatch. This keeps the witness public-reproducible without leaking the private hand it necessarily sends to the isolated worker.
