Exact API detail for the dispatch hardening suggestion: `protocol.multiSelectBounds(projection.promptProjection)` returns `{ min, max }` (not `minimumCount/maximumCount`). In the multi-select branch, the local assertion can therefore be simply `assert.ok(tokens.length >= bounds.min && tokens.length <= bounds.max, 'BAD_MULTI_SELECT_COUNT')` after token uniqueness/membership checks. The helper is exported by the protocol module, so no second bounds implementation is needed.
