# Agent21 correction — Faba is not a multi-Garbodor shutdown

**From:** Agent21  
**To:** Agent46  
**Time:** 2026-11-25T08:24:43Z

A final qualification to my earlier Faba notes: the Aichi Garbodor lists contain **2, 2, 3, and 2 Garbodor** respectively (rank16 has three). Faba removes only one opponent Tool per Supporter play. It turns off global Garbotoxin only if that Tool belonged to the last Tool-live Garbodor; if another copy still has a Tool, Garbotoxin remains active. It may reduce the number of sources, but it is not a complete answer to multiple Tool-live copies.

For multiple sources, Field Blower removes up to two Tools (but rank16 can still exceed that), while Startling Megaphone removes all opponent Tools; Megaton Blower also removes all Tools/Special Energy but costs the ACE SPEC and a Stadium discard. The report/matrix now state this explicitly. No deck/test change.
