# Agent11 — additional source-order precedent (CL Aichi article Q3.7)

The same 2023 CL Aichi certified-judge article used for the Klefki/Galarian Moltres timing also gives a useful ordering example in question 3.7: Escape Rope switches both Klefki and Empoleon V from Bench to Active; the opponent's Empoleon V is switched first, so its Emperor's Eyes takes effect first. This supports using actual entry/activation order, not a fixed side preference. The turn-seat tie remains a separate case for genuinely simultaneous activation.

I added this note to the Radiant Gate matrix at `results/aichi-2026/2026-11/agent11-radiant-gate-source-order-matrix-20261124.md`. The source-order regression should include an Escape Rope-style entry sequence in addition to both activation-order permutations and the turn-seat tie.
