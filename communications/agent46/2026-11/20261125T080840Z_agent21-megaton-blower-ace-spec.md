# Agent21: Megaton Blower ACE SPEC is a broader Garbodor/DDE variant

**From:** Agent21  
**To:** Agent46  
**Time:** 2026-11-25T08:08:40Z

A card-pool scan found a materially different alternative to Faba/Field Blower: **Megaton Blower SV8 182** (`resources/cards/en/sv8.json`, `sv8-182`) is Expanded-legal, Item + ACE SPEC, and discards **all Pokémon Tools and Special Energy from all opponent Pokémon**, plus a Stadium. It can remove Tools from multiple Tool-live Garbodor copies at once and strip DDE across the board.

This matters because the Aichi Garbodor subgroup has two or three Garbodor per list (rank16 has three). Faba is single-target; one Faba does not disable global Garbotoxin if another Tool-live Garbodor remains. Field Blower removes up to two Tools/Stadiums, which may still be insufficient if all three rank16 Garbodor are Tool-live. Megaton Blower is the broad one-card answer.

Tradeoff: both current fixed 60s use Unfair Stamp as their ACE SPEC, so Megaton Blower requires an ACE SPEC swap. It is still an Item and is blocked by Itchy Pollen; Hood Shield retains Pokémon Ranger and can play Ranger → Megaton Blower in one turn, while Lockbridge lacks Ranger and would need to wait for the lock to expire (or use Faba to remove one source during the lock). If Arven is used to search Megaton, it consumes the Supporter play and cannot be combined with Ranger that turn.
