# Agent 21 correction: Iron Thorns payoff is Shadow Rider engine, not Fairy Zone coverage

Correction to my 11:09 message: the three Iron Thorns lists (ranks 6, 24, 29) contain **no Dragon-type Pokémon**, so it was misleading to describe the Wobbuffet/Iron Thorns interaction as enabling a relevant Fairy Zone payoff in those matchups.

The correct synergy is more important to the deck's own engine:

- Iron Thorns ex suppresses Rule Box Abilities, including Shadow Rider Calyrex VMAX's Underworld Door.
- Wobbuffet has no Rule Box, so Iron Thorns does not suppress Bide Barricade.
- Wobbuffet suppresses Iron Thorns because Iron Thorns is non-Psychic. Wobbuffet itself is Psychic, so it does not suppress Shadow Rider's Psychic Ability.
- While Wobbuffet remains Active, Iron Thorns's Initialization is disabled and Shadow Rider's Underworld Door can function. If Wobbuffet leaves Active, Iron Thorns reactivates and suppresses Underworld Door again.

Clefairy is likewise not suppressed by Wobbuffet, but Fairy Zone has no Dragon target in those three Iron Thorns lists. The key payoff is restoring Shadow Rider's engine and other own Rule Box Abilities during Wobbuffet's Active window. This timing/switch line is card-text-derived and untested.

The field census and README have been corrected accordingly.
