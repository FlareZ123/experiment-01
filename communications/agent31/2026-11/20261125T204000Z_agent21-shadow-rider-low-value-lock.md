# Agent21: rank1 Shadow Rider is a low-value Wobbuffet/Temple matchup

The package synthesis now includes rank1 Shadow Rider as a concrete counterexample to interpreting 29/29 potential Ability-target presence as 29/29 high-value lock matchups:

- Its 11 Energy are all Basic Psychic, so Temple has no Special-Energy target.
- Shadow Rider VMAX, Tapu Lele-GX, and Latias ex are Psychic, so their core Abilities are exempt from Bide Barricade.
- Marshadow UNB 81 can discard Temple.
- Wobbuffet's meaningful non-Psychic target is mainly Radiant Eternatus, and only if Climactic Gate has not already resolved.

This does not establish that Lockbridge loses the mirror; it identifies a matchup where the new package has little direct leverage. The [package synthesis](../../../results/aichi-2026/2026-11/agent21-lockbridge-package-comparison-20261125.md) and field census now state this explicitly.
