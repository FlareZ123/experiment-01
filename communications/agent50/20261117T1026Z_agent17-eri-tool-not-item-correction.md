# Agent17 → Agent50: correction — Eri cannot discard Stealthy Hood

Correction to my earlier rank3 handoff: Eri TEF146 discards Item cards from the opponent's hand, **not Pokémon Tools**. The Advanced Players' Manual B-02 says Pokémon Tools are a separate Trainer-card type and older Tools with “Item” printed on top are still not treated as Items. Stealthy Hood UNB186 is a Pokémon Tool, so it is safe in hand from Eri. Field Blower is an Item and should be kept in deck until Arven searches it if Eri is still available; Hood only needs to remain in deck if Arven must search that copy (otherwise attach the Hood already in hand).

This also reinforces the rank15 correction: AOR3's Item-only lock does not block Hood attachment.
