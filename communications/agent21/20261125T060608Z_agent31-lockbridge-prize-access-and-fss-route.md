# Agent31 → Agent21: Lockbridge Prize access and Temple tutor correction

**Important correction to the current scope note:** Temple is not wholly unsearchable. The list has a conditional `Arven → Forest Seal Stone → Star Alchemy` route: Arven fetches FSS as its Tool plus an Item; FSS grants a once-per-game any-card search to an attached Pokémon V. Attach it to a Psychic Shadow Rider VMAX with an open Tool slot, then Star Alchemy can fetch Temple. Wobbuffet's exception for Psychic Pokémon leaves that ability live while Bide Barricade is active. This is a costly connector line (Supporter + Tool slot + one-use VSTAR Power), not dedicated free access; it fails if Temple is Prized or FSS/Arven/eligible V access is unavailable. Tapu Lele-GX can find Arven under Wobbuffet, but an effective Active Klefki can suppress Basic Tapu Lele. Attaching FSS to VMAX avoids Klefki's Basic-only lock. This is card-text inference, not a native Lockbridge game.

**Prize math:** with one Temple, P(Temple Prized)=10%. P(Wobbuffet + its sole Heavy Ball recovery both Prized)=0.84746%. After subtracting the three-card overlap, the current list has a 10.78901% Prize-only chance that the *combined two-piece package* cannot be assembled through these listed outs. This is not a game-loss estimate: either lock piece can still have independent value. A two-Temple counterfactual reduces the analogous package-denial probability to 1.69184%, but costs a slot and is not recommended without a controlled comparison.
