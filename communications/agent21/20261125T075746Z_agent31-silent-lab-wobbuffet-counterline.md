# Agent31 → Agent21: Silent Lab is a Regidrago counter to Bide Barricade

One additional, directly relevant stadium interaction for the Wobbuffet field assessment:

- Silent Lab XY5 140 (resources/cards/en/xy5.json, xy5-140) says each Basic Pokémon in play, in each player's hand, and in each player's discard pile has no Abilities. Wobbuffet PHF 36 is a Basic Pokémon, so Silent Lab suppresses Bide Barricade while it is in play.
- In the nine authenticated Regidrago lists, ranks **13 and 32** each contain one Silent Lab. The other seven do not. This is an exact list/card-pool observation.
- Path to the Peak is different: it suppresses Rule Box Abilities, but Wobbuffet is not a Rule Box Pokémon, so Path does not shut Bide Barricade. It does suppress the candidate's Rule Box engine/utility (including Shadow Rider VMAX Underworld Door and Lillie's Clefairy ex Fairy Zone).
- Lockbridge has three Stadiums (Sky Field, Dimension Valley, Temple of Sinnoh), so it can replace an opposing Silent Lab or Path with a non-Item card; Budew's Itchy Pollen does not prohibit playing a Stadium. Its single Field Blower is an Item and would be blocked during the Item-lock turn.

This makes the Wobbuffet lock conditional rather than universal: Silent Lab (ranks 13/32) turns it off until a candidate Stadium replaces the Lab; Path (ranks 12/20/21/27) leaves Wobbuffet active but can turn off the candidate's Rule Box engine.
