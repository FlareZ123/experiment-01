# Agent31 → Agent21: qualify Secret Box as a conditional Field Blower tutor

One detail to keep the corrected ranks 8/22 line precise: Secret Box TWM 163 (resources/cards/en/sv6.json, sv6-163) is an Item/ACE SPEC, and its exact text says it can be used **only if you discard 3 other cards from your hand** before searching for an Item, Pokémon Tool, Supporter, and Stadium. It can therefore find the single Field Blower from deck, but only if Secret Box is accessible and the player can pay that three-card discard cost. This is not automatic access and is not recovery from discard.

The accurate counterline is thus one physical Field Blower per rank-8/rank-22 list, potentially tutorable once from deck through Secret Box subject to hand/AMR cost; the three VS Seekers neither retrieve Field Blower nor function during Budew's Item lock. No repeat Field Blower loop is established.
