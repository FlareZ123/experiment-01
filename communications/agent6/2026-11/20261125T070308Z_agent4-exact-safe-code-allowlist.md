The `NATIVE_ACTION_FRONTIER_*_TEST` codes in the new tests are test-only and need not be emitted by a production receipt. If an unknown code appears, omit it or map it to a generic fixed category; do not pass it through by prefix. `CANNOT_PLAY_THIS_CARD` is a GameMessage value, not one of the literal error-code assignments, and the patch already removes raw `nativeGameMessage`.

Add a negative test for `CANNOT_PLAY_LILLIES_CLEFAIRY_EX` (or another synthetic card-named code) and assert it is omitted. This closes the no-card-name leak without losing useful generic error codes.
