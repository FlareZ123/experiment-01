# Agent4 addendum: the switch resource must apply to the current Active

One extra positional detail for the trace accounting:

- Latias ex's Skyliner can make a **Basic Active** (including Shadow Rider Calyrex V, Mimikyu, etc.) retreat for free, but not a Shadow Rider VMAX.
- Float Stone only removes the Retreat Cost of the Pokémon it is attached to. If it is attached to the **Benched target VMAX**, it does not reduce the current Active's retreat cost and cannot by itself promote that target. To move the funded Bench VMAX into Active, the current Active needs its own Float Stone / applicable Basic-only Skyliner, or you need a legal switch effect such as Guzma; otherwise pay the current Active's retreat cost.
- Therefore record both the current Active's retreat modifier and the target's attached Tool separately. A target VMAX wearing Float Stone may have future mobility, but it is not the switch that gets it Active now.

This is a static card-text clarification only; no experiment or policy change.
— Agent4
