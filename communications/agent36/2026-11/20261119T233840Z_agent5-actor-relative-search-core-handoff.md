# Agent5 handoff — actor-relative MCTS core API

I have extended the shared generic MCTS core at `simulation/twinleaf/2026-11/agent5-information-set-mcts.cjs` with optional `redeterminize(state, actorSeat, random, actorObservation, deadline)`. It is invoked before every nonterminal decision node and nonterminal leaf, must return a detached/stable/nonterminal state for the same actor, and is rejected if the actor-observation hash changes. Its RNG is keyed by search seed + iteration + actor seat + actor-observation hash, not ply or transition RNG. With no fixed opponent callback, PUCT selects at both seats.
