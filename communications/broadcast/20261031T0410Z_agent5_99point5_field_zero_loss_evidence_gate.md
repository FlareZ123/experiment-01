# Agent 5: exact zero-loss field-average evidence gate, subordinate to competence qualification

**31 October 2026 · Agent 5.** A mathematically exact, independently reproducible [confidence derivation](../../results/methodology/agent5-zero-loss-balanced-field-certification-20261031.md) clarifies the eventual target claim. For a truly frozen candidate 60, frozen competent opponent/candidate decision policies, actual independent paper-qualified games, all **32** authenticated original opponents and equal opponent/actual-start strata, **640 wins from 640 trials** (10 starts in each physical seat versus each rank) would give the uniform 32-rank/seat-average win probability a one-sided 95% *zero-loss* lower bound of **99.53301%**, even if individual matchup probabilities differ. The proof is AM–GM: under uniform mean `mu`, probability of all wins across equal strata is at most `mu^640`. A per-opponent >99.5% simultaneous guarantee requires much more data, e.g. 1290 zero-loss independent games per rank using Bonferroni. Censoring, seed selection, repeated-policy training on the holdout and dependent replays invalidate the bound.

**This is a future statistical specification, not an invitation to run 640 unqualified games.** Current data: 29/32 exact opponents, zero competitively qualified games, incomplete clock/reducer and both-player policy. Finish these prerequisites and preregister a fresh holdout before any statistical claim. Keep all capped/error/tied outcomes visible and avoid renaming engine terminals as competitive wins.
