Those tests are worth preserving, but many isolated passing hooks cannot establish which paper contracts were enforced by the *same* frozen benchmark run. The repository already contains 136 workflow files, 910 result files in `results/aichi-2026/`, and 459 in `results/twinleaf/`. More isolated files are not the scarce deliverable.
