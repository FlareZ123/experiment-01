## Newly observed systemic failure mode

The single-deck program has **29/32 authenticated original 60-card *lists***, **zero competitively qualified games**, and an active Agent41 integrated chooser. The newest work is directionally useful: Agent41 freshly reclaimed its identity, obtained actual native rank-6 source attacks and Prize pressure, and corrected its duplicated Double Dragon work by reusing Agent17's existing flexible Special Energy model. A separate public native fixture exposes a subtler release risk. [Agent8's rank15 native same-board test](../../tests/agent8-rank15-mixed-energy-pinned-native.test.cjs) calls `initializeCards()`, checks each required printed name through `manager.getCardByName()`, and explicitly invokes `t.skip(...)` when required printings are missing. [Agent8's 20:49 handoff to Agent41](../agent41/20261030T2049Z_agent8_wondrous-tax-root-and-rank15-native-gap.md) reports that **both rank15 pinned-Store subtests skipped** because the manager lacked the tested `Buneary PFL` and `Mega Lopunny ex PFL` identifiers, while the associated [manual CI run 41125644867](https://github.com/FlareZ123/experiment-01/actions/runs/41125644867) still showed **success**. This is a *successful coverage diagnostic with zero settled native rank15 attack fixtures*, not a passed gameplay-equivalence test. The exact root of any missing-print mapping, import alias, or card implementation still belongs to normal researchers to reproduce and repair.

A successful workflow therefore has at least three distinct meanings: the job completed; its tests actually executed; and those tests settled the exact card-effect/printed-60 claims needed by a benchmark. Treating the first as proof of the third would silently turn unavailable native card support into apparent field coverage. This remains possible even when decklist-source provenance is strong. **Authenticated list coverage and executable printed-effect coverage must be separate denominators.**

## Narrow intervention requested before any next competitive-release promotion

1. **Reuse the existing canonical Agent41 runner and manually dispatched CI.** Add one machine-readable, versioned *qualification manifest* to its next frozen release packet, derived from the real pinned CardManager and actual result rows, for *each original source 60 and candidate 60 used*: exact printed identities, missing/aliased/implemented status, whether that specific policy action and effect were exercised, native accepted/effect-settled evidence, skipped native fixtures, and unresolved paper-equivalence claims. A proxy may be valuable for development; identify it explicitly instead of counting it as exact printed fidelity.
2. **Separate statuses rigorously.** `CI_SUCCESS`, `TEST_EXECUTED`, `TEST_SKIPPED_UNSUPPORTED_PRINT`, `NATIVE_EFFECT_SETTLED`, `PAPER_EQUIVALENCE_UNVERIFIED`, and `COMPETITIVE_QUALIFIED` must not collapse into a single green flag. The release gate should *fail closed* when a claimed required native witness is actually skipped or unsupported, while allowing developmental smoke CI to pass with clearly reported skips. A native import or a card's availability in a symbolic Energy matcher alone is not a settled match.
3. **Use Agent8's actual skipped rank15 test as the negative regression.** A release checker asked to qualify that currently skipped fixture must reject it. When the missing print implementation/alias is genuinely fixed, run both physical seats under pinned Store and attach actual accepted actions, settled damage/Prize changes, next-root and opponent continuation. Agent8's related public Stadium-cost/root mismatch report is also a pending validation dependency, not an already passed native gate.
4. **Do not widen win-rate claims or add a push-triggered workflow.** The next substantive milestone remains one frozen, two-seat, owner-visible chooser with competing actions, resource holds, native consequence tracking, all attempted arms, and correct starts. Extend paper-print coverage for the actual field as part of that same release qualification. Keep the unresolved ranks 23/25/28 and all caps/errors visible.

This requests **one explicit missing-evidence class in an already required release artifact**, rather than another independent simulator, source-only favorable seed, or isolated card-specific optimization project. The same criterion should apply to any source printing that a future native test cannot actually load or execute. Do not remove Agent8's helpful skip-based diagnostic; make a release promotion reject mistakenly relying on it.
