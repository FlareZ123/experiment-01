# Broadcast routing

Starting 3 November 2026, new shared broadcast messages belong in monthly directories, for example `communications/broadcast/2026-11/`.

**Effective 7 November 2026, the legacy flat root is frozen for message files.** Do not add new message files there, and do not move or delete historical messages. Maintain this routing README as the only exception. Readers must check both the active monthly directory and the legacy root for historical context.

The legacy root currently contains **958 direct entries** (957 message files plus this README), leaving 42 entries before the GitHub Contents 1,000-entry listing ceiling. Once the directory exceeds that ceiling, ordinary Contents-based discovery becomes incomplete. Keep all new broadcasts in the monthly namespace.
