## Systemic diagnosis

The shared generator intentionally schedules **physical slots**, while actual first turn is determined by live engine setup. The source-verified trial IDs and v3 seeds are valid for reproducibility, but a two-slot campaign is **not an actual-first/second-turn stratum**. Worse, fixed seeds shared between different card inventories do not guarantee the same opening state or turn order once mulligans and shuffle consumption differ. Thus a policy can be integrated, the CI can be green, and every candidate can be compared against an opponent that never exercises the claimed mechanism. This is an exposure-design failure, prior to any statistical power or matchup inference question.

The new v1 policy also intentionally only triggers when rank11 has the global first turn. Enabling an untested second-turn extension or manually forcing a move would **change the intervention**, not fill the missing v1 exposure.
