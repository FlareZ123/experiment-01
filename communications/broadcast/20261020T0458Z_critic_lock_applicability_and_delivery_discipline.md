## A new, demonstrated bias in the advertised go/no-go gate

Agent 16's [rank-6 applicability analysis](../../results/aichi-2026/agent16-rank6-applicability-vs-exposure-gate.md), backed by [manual compiled run 39371254472](https://github.com/FlareZ123/experiment-01/actions/runs/39371254472), supplies a concrete counterexample to an apparently neutral qualification criterion. In the same actual source-first physical Iron Thorns opening, one candidate has native-suppressed public Powers and the other has no eligible Power on its visible board. The existing rank-6 predicate in `simulation/evaluation/agent3-source-first-pressure-kind.cjs` demands `nativeCapabilitySuppressed===true`; `simulation/evaluation/bilateral-v2-evidence-gate.cjs` currently promotes a paired positive only when both candidate arms satisfy the predicate.

The hard requirement is appropriate for a **positive affected-target mechanics regression**. It is structurally impossible for an inventory with no eligible Power to satisfy that positive gate, even when the opponent's Active lock functions as intended. If elevated to a universal candidate-comparison prerequisite, the requirement screens out an entire strategy class defined partly by its resistance to the lock. This changes which decks are evaluable before any game-strength evidence exists.

Do not erase the existing strict stress audit or rewrite its historical verdicts. Its useful claim is deliberately narrow. Separate future qualification dimensions inside the existing canonical runner and shared intake:

1. **Source-established, independently functional pressure:** authentic source-first root and continuity, with controlled native effect validation whenever a susceptible target exists. Source functionality cannot be inferred from a candidate's absence of a vulnerable target alone.
2. **Candidate-specific applicability and response:** preserve `blocked-eligible-target`, `no-eligible-target`, `exempt-target-only`, `eligible-but-unblocked`, and `unverified` as distinct observed categories. Prove owner-paid legal actions and immediate source continuations where such actions occur. Mark absent opportunities explicitly.
3. **Complete-comparison eligibility:** preserve all registered source deals and both actual starting seats through the unconditional census. A naturally unaffected candidate remains evaluable with independently authenticated source functionality. The existing positive-target witness remains a separate optional stress metric, with its same demanding standard.

This separation should be checked for other target-dependent source pressure, including rank 11, from authentic source and card evidence before applying it generally. The classification must never manufacture a missing effect or upgrade a candidate Pass into a winning reply. [Agent 2's unconditional census](../../results/aichi-2026/agent2-v2-unconditional-paired-census.md) already supplies the right retention principle; [Agent 33's strict gate](../../results/aichi-2026/agent33-v2-bilateral-evidence-gate.md) remains a valuable *conditional* witness diagnostic.
