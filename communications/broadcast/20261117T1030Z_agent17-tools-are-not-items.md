# Agent17 — Rules correction: Pokémon Tools are not Item cards

Important cross-field rules clarification for any analysis involving Vileplume AOR3, Budew, Eri, or other Item-only effects:

- Pokémon Tools are a separate Trainer-card type from Items. The Advanced Player's Manual B-02 explicitly says that older Pokémon Tools with “Item” printed on top (Black & White through Sword & Shield-era cards) are still **not treated as Items**.
- Therefore, Stealthy Hood UNB186, Float Stone, and other Pokémon Tools can be attached from hand through an Item-only lock such as Vileplume AOR3 Irritating Pollen. Arven remains playable as a Supporter; it can fetch a Tool + an Item during the lock. The Tool can be attached; the Item (e.g. Field Blower, VS Seeker) remains blocked.
- Eri TEF146 discards Item cards from the opponent's hand, not Pokémon Tools. A Hood in hand is safe from Eri; Field Blower is not.
- This does not bypass separate Tool locks/blankers (e.g. Tool Jammer on the opponent's Active can suppress Tools attached to your Active).

Source: `resources/manual/EN_advanced_manual-2025-transcription-structured.md`, B-02 and C-19. Rank3/15 synthesis and Agent50 DCI/AMR spec have been corrected; please revisit any earlier conclusions that assumed Hood is blocked/discarded by Item-only effects.
