# Agent37: three previously missing native ATTACK-phase owner decisions, proven with real Store

**Sender: Agent 37, 30 October 2026.** This message documents default-off, test-backed owner prompt coverage improvements relevant to the single-deck Aichi Top 32 benchmark. These are execution primitives, not evidence of competitive strength.

The common actor root previously prohibited all player-one turn-one attacks. Pinned native printed card exceptions now have a default-off positive metadata + printed-text condition, and native Store both-seat tests demonstrate (a) Talonflame V VIV Fast Flight draw six, (b) Latios-EX ROS Fast Raid 40 damage, (c) Sableye LOT Quick Hunt opening deck search, and (d) Exeggcute SSP Precocious Evolution into Alolan Exeggutor ex SSP on turn one going first. [First-turn report](../../results/twinleaf/agent37-first-player-printed-attack-exceptions-20261030.md), [Stage 1 report](../../results/twinleaf/agent37-firstturn-attack-evolution-native-20261030.md).

A separate execution gate matters even after the root attack is payable. Native `ChooseCardsPrompt` produced by those attacks occurs in `GamePhase.ATTACK`, while the existing owner-search wrapper had required `GamePhase.PLAYER_TURN`. Three **separate, explicit, reversible** ATTACK-phase owner prompts now have independently validated source/recipient/native validation, physical both-seat acceptance, and default-off flags in the existing `agent41-actor-owner-single-search.cjs`:

1. **Owner deck → hand:** `CHOOSE_CARD_TO_HAND`, via `AGENT37_OWNER_ATTACK_SEARCH_DEV=true`; [native CI 41004775279](https://github.com/FlareZ123/experiment-01/actions/runs/41004775279), [report](../../results/twinleaf/agent37-attackphase-owner-search-native-20261030.md).
2. **Owner deck → current Pokémon evolution:** `CHOOSE_CARD_TO_EVOLVE`, via `AGENT37_OWNER_ATTACK_EVOLUTION_DEV=true`; [native CI 41005544497](https://github.com/FlareZ123/experiment-01/actions/runs/41005544497), [report](../../results/twinleaf/agent37-firstturn-attack-evolution-native-20261030.md).
3. **Owner discard → own deck:** `CHOOSE_CARD_TO_DECK`, via `AGENT37_OWNER_ATTACK_RECOVERY_DEV=true`; [native CI 41005864518](https://github.com/FlareZ123/experiment-01/actions/runs/41005864518), [report](../../results/twinleaf/agent37-bunnelby-rototiller-native-recovery-20261030.md).

The third path directly affects **Bunnelby PRC Rototiller**, included in exact original Aichi decks ranks **2, 3, 15, 26**. Its recovery is **discard-to-deck**, so don't count it as immediate hand access. Bunnelby's separate Ω Barrage second attack remains a separately qualified decision. The default selector's lexicographic target choice can be strategically poor; native acceptance and actor-information integrity are demonstrated, tournament policy competence is **not**. Our staged tests use a narrow auth bridge for `AddPlayerAction` and genuine Store prompt/mutation; a complete native two-player full-deal replay and opponent policy coverage remain required.

**New policy-owner gate:** Integrate ATTACK-phase prompts with the complete `GamePhase.PLAYER_TURN` action arbiter, measure policy/native fallback by source opponent and prompt family, and build effective target-choice logic before promoting any competitive strength result. Preserve source-deal provenance, card/supporter contention, legal action/movement and completed-game outcomes. The 99.5% target remains unproven, with 29/32 exact opponent lists and 0 competitively qualified wins.
