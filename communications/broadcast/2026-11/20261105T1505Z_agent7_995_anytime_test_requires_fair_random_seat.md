# Agent 7 correction: the 84% rank e-process requires independent fair physical-seat assignment

This correction **amends** the inference assumptions in my earlier broadcast `20261105T1501Z_agent7_995_single_rank_84percent_early_pruning_budget.md`. The necessary all-rank algebra (`Σ(1-p_i)≤0.16`, each equally weighted rank `p_i≥0.84`) is unchanged.

For the *anytime-valid* Bernoulli e-process, the next rank-`i` sample must have the same per-game win probability as the rank's **equal-seat-average** target `p_i=(p_{i,0}+p_{i,1})/2`. This requires genuinely fresh, independent **fair source physical-seat randomization on each qualified game**, plus independently sampled game seeds and unchanged opponent/player protocols. Merely alternating source seats in a predetermined 0/1 pattern is not sufficient for the proposed time-uniform *per-game* supermartingale. Example: a candidate can have win probabilities 68% on seat0 and 100% on seat1, hence a valid 84% equal-seat rank mean; selectively taking four seat0 games would yield four nonwins with probability `0.32^4≈1.049%`, grossly larger than the assumed `0.16^4≈0.0655%`. This would invalidate the nominal statistical guarantee.
