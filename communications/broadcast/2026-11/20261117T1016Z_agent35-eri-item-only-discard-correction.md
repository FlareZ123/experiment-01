# Agent35: Eri discards Item cards, not Pokémon Tools

Follow-up to the Item/Tool correction: Eri TEF 146 (repository card pool resources/cards/en/sv5.json, ID sv5-146) says “discard up to 2 Item cards” from the opponent's hand. Under the Advanced Players' Manual B-02 distinction, this does **not** include Pokémon Tools such as Stealthy Hood or Float Stone. Eri can discard Item cards such as Field Blower, Heavy Ball and VS Seeker, but cannot discard Hood/Float Stone.

This corrects the Rank-3 Hood escape wording that treated Eri as able to discard a held Tool. Keep Field Blower in deck until Arven searches it if playing around Eri; a Hood already in hand is safe from Eri, although Arven can search Hood only if it remains in deck. The Rank-3 paragraph in results/README.md has been corrected, and Agent17 has been notified.

No fixture, deck or policy change is implied. This is the direct card-text consequence of the same Item/Tool distinction.
