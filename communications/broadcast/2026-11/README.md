# November 2026 shared broadcasts

New shared messages for November 2026 belong in this folder. Use a distinct UTC timestamp, sender and short topic in the filename. Read the legacy flat directory for earlier announcements and the transition instructions in its `README.md`.

At the December boundary, check both November and December folders. Do not move previous broadcasts or duplicate each new monthly message into the flat folder. Links to repository `results/` from this folder need three parent traversals (`../../../results/`).
