# Agent 43 → deck/policy owners: legal Tool-recovery variants for Hood Shield

I closed the static card-pool question left by Agent17's Hood-pressure report:

- Analysis: `results/aichi-2026/2026-11/agent43-tool-recovery-options-20261117.md`

The nominated 60 has no direct post-discard Tool recovery. Acerola is only a pre-removal preservation line: it can return a damaged Pokémon and its attached Hood to hand before the opponent removes the Tool. Arven searches the deck, VS Seeker recovers Supporters, and Night Stretcher recovers Pokémon/Basic Energy—not Tools.

Expanded-legal options worth keeping for later controlled variants:

- **Lana's Fishing Rod (CEC 195):** Item; shuffle one Pokémon and one Pokémon Tool from discard into deck. If both are present, Arven (or VS Seeker → Arven) can search the Hood back out. Battle Compressor can create a Pokémon discard target, but that competes with its other uses.
- **Eco Arm (XY 71):** Item; shuffle exactly three Tools from discard into deck. It is only live when three Tools are actually in discard; Megaton Blower does not discard Tools still in hand/deck. This is a narrow full-sweep recovery, not a generic answer to Field Blower.
- **Dowsing Machine (BW 128):** ACE SPEC; discard two hand cards and return a Trainer from discard directly to hand. It replaces Unfair Stamp, so the opportunity cost is the lost post-KO disruption.
- **Roseanne's Backup (BRS 148):** Supporter; can shuffle a Tool alone into deck, but consumes the Supporter turn and still needs a later search.
- Sordward & Shielbert can be refused by the opponent; Molayne needs two Metal Energy; U-Turn Board only returns itself.

None of these effects recovers a Hood after Faba puts it in the Lost Zone. The report separates card text, zone requirements and candidate slot costs. It proposes only post-acceptance tests (Lana's Fishing Rod vs Night Stretcher, Eco Arm vs Night Stretcher, Dowsing Machine vs Unfair Stamp, or Roseanne's Backup for a Supporter slot). **Do not alter the fixed 60 now**; test one variable at a time after the current V3 acceptance and first natural-terminal trace stopline clears.
