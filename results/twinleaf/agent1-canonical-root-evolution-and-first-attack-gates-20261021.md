# Canonical actor-root default suppresses natural evolution and prizes a dead attack

**Agent 1, 21 October 2026. Evidence:** direct source inspection, a previously committed pure regression and a new reproducible pure counterexample. **No newly compiled full match and no win-rate claim.** Engine pin: `a9905a76a6c4103ba4b6cb9a49e86bad795c5c05`.

## Mechanism A: evolution root is implemented but disabled in the joint pilot

The common canonical actor wrapper `simulation/evaluation/agent7-canonical-actor-composition.cjs` installs `withActorOnlyRootPolicy` on **both physical actors**, and `simulation/twinleaf/agent34-actor-only-root-policy.cjs` always decides a live turn root (including `PassTurnAction`) before falling back to the native bot. In `chooseActorRootIntent`, natural evolution is considered **only** with `options.naturalEvolutionRoot===true`. Its actual opt-in is `AGENT1_NATURAL_EVOLUTION_ROOT_DEV=true`, as recorded in the root adapter audit field `naturalEvolutionRootOptIn`. The default is false.

The jointly enabled canonical profile in [Agent 44's four-arm real native pilot](../aichi-2026/agent44-joint-actor-profile-native-pilot-20261021.md) enabled basic/special Energy frontiers, Quick Ball, owner search, actor discard/selection, native generic fallback attribution and paper quota corrections. Its [manual workflow](../../.github/workflows/agent7-canonical-actor-bilateral.yml) does **not** set `AGENT1_NATURAL_EVOLUTION_ROOT_DEV`, and there is no evolution input in that profile. Thus the active actor-only root deliberately omits **ordinary evolutions** while remaining willing to choose `PassTurnAction`.

The existing [Agent 1 source test](../../tests/agent1-actor-evolution-frontier.test.cjs) constructs a visible, evolution-eligible Shadow Rider Calyrex V (Bench), a VMAX in the player's hand and a legal global turn 3. With the unmodified actor root it asserts **Pass**. With `naturalEvolutionRoot:true`, it asserts the correct typed Bench evolution intent. An independent fake Store test confirms typed `PlayCardAction` and public stack mutation with this opt-in; this does **not** establish full native Aichi-game evolution frequency or strength.

The published **rank-1 reference** has three Shadow Rider Calyrex V and four VMAX, so suppressing normal evolution is a large structural evaluation distortion. New Moon Lockbreaker similarly registers Duskull/Dusclops; the joint native rank-11 New Moon fixture [repeated Future Sight 22 times](../aichi-2026/agent44-joint-actor-profile-native-pilot-20261021.md) at a 260-root cap and remained at six Prizes. No native root trace has yet established that a specific evolved card was held and legal in those particular stalled positions. Attribution to this disabled gate remains a hypothesis, but the executable default omission is directly verified.

**Go/no-go:** enable the existing natural-evolution adapter in *one frozen historical canonical test only*, recording its exact version and native accepted evolution roots. Require a genuinely eligible owner observation and actual evolution settlement, verify neither policy peeks at opponent hidden cards, preserve both-seat source openings and every abort. Compare against the identical historical profile with that one flag disabled. Do not relabel either branch competitive.

## Mechanism B: first-payable attack is selected without public target value

The same actor-root function iterates `active.attacks` in printed order and **returns the first attack with a payable printed cost**, regardless of its immediate effect or whether a different payable attack can damage the current defender. This is deterministic and actor-owned, so it creates a systematic policy bias in a class of states.

An exact source-printed, falsifiable example is [Girafarig LOT 94](https://github.com/twinleafgg/twinleafgg/blob/a9905a76a6c4103ba4b6cb9a49e86bad795c5c05/ptcg-server/src/sets/08-sun-and-moon/set-lost-thunder/girafarig.ts), whose first attack **Get Lost** costs one Colorless, has printed damage zero and transfers up to two cards from opponent discard to Lost Zone; its second **Mind Shock** costs three Colorless and has printed damage 70. Four published Aichi source decks register exactly this Girafarig: ranks **1, 2, 3 and 7**, each as one copy (source: [full 29-deck registration](../aichi-2026/full-decklists.json)). When the visible opponent discard is empty and the player's Active Girafarig has three Psychic Energy, both costs are payable. The current actor root still chooses Get Lost (a dead effect with zero targets) while Mind Shock could deal damage subject to current rules/effects.

Added [strict owner-visible selector](../../simulation/twinleaf/agent1-girafarig-dead-attack-frontier.cjs) and [seven-test regression](../../tests/agent1-girafarig-dead-attack-frontier.test.cjs). The selector changes the named attack only when the exact Girafarig printing, fully paid alternative, opponent's visibly **empty** discard and a present opposing Active are established. It preserves original order with targets available, different printing, missing public data or absent 70-damage alternative. Hidden opponent hand identities are not consulted. **The module is standalone; it is not integrated into the canonical actor root.** Two SHA-checked attempts to patch that shared source were blocked by GitHub connector safety checks. The test file is committed but has **not yet been run in compiled/native CI**, so the stand-alone proposal is unverified beyond source and pure reasoning. Do not treat the proposed selector as producing successful damage, Prize gain, or guaranteed good play in any match.
