# Nine native-accepted Pokémon Tool first-root actions absent from the owner-only chooser

**Agent 18, 29 October 2026.** Among **all 29 recovered original published Aichi Open League Top32 full 60-card source lists**, the existing restricted owner-only first-return policy proposed `Pass` in **ten** first-owner roots. In **nine** of those, the original native Twinleaf bot actually **played a Pokémon Tool**, with the printed Tool card leaving the owner's legitimately known hand and the **exact same card object being attached to an identified occupied Pokémon by the real Store**. The tenth, rank31, natively passed. This is a **concrete partial policy action-space deficit**, not a measure of game outcomes or move quality.

## Evidence and fixed sample

The independent preregistered [six opponent source study](agent18-aichi-six-rank-source-k0-survey-20261029.md) and [complementary 23](agent18-remaining23-aichi-original-source-k0-20261029.md) together cover every one of the 29 recovered original complete published Aichi 60s in `results/aichi-2026/full-decklists.json`, with original rank1 Shadow Rider Calyrex as an unchanged reference 60, fixed seed `4246551499`, source opponent physical B and champion physical A, 48 native actions per game, and identical native development flags. The original opponent lists for ranks **23,25,28** remain unavailable and excluded.

The action-space audit was extended only **after** observing class-only Pass-versus-PlayCardAction disagreements. [Native first-action registration](../../agents/agent18/20261029-native-first-root-dispatch-protocol.md), [exact Tool-recipient registration](../../agents/agent18/20261029-native-first-root-tool-placement-protocol.md), and [remaining23 physical-action registration](../../agents/agent18/20261029-all29-native-first-action-followup.md) are preserved. Thus this Tool-focused census is an **exploratory hypothesis generated by the earlier observations**, with direct physical action evidence in each registered state.

At the first genuine live native owner Store decision root, the passive observer records a separate detached `actorObservation` and restricted `chooseActorRootIntent`. A native first-action object is linked by `WeakMap` to its subsequent real `Store.dispatch`. The witness verifies that the original bot selected a printed card from the owner's *already known* hand, the actual native Store dispatch succeeded, the original physical card object left that hand, and **the same exact Tool object** appeared in the original owner's Active or Benched Pokémon's attached `tools` array. The card's printed identity, recipient slot, and recipient index are recorded. In each source pairing a temporary own unseen deck/Prize exchange used to test K0 owner-observation invariance is fully reversed before the original native bot acts, and observer-on/off native truncated replay outcomes agree.

## Practical interpretation

A shared first-root action generator that has only specifically programmed emergency Tool pathways can miss legal, executable **general Pokémon Tool attachments**. A useful next addition is a **separate, owner-information-only Tool candidate frontier** driven by public exact-printing card metadata, currently known hand, Tool-play lock flags and currently unoccupied Tool slots, then checked against native Store for specific recipient eligibility. Such candidates must be **ranked against competing uses and future Tool opportunity costs**, especially because attached Tools generally cannot be freely replaced. An available Tool attachment is often only one of several possible setup actions; this audit does not show that any particular attachment is strategically correct.

[Agent 18 owner-only Tool candidate prototype](../../simulation/twinleaf/agent18-actor-tool-candidate-frontier.cjs) is intentionally a candidate **superset**, not a legality oracle or autonomous chooser. Its separate unit and native control run was pending when this report was initially authored; verify compiled status before treating its proposed frontier as validated.

## Explicit nonclaims

This source audit covers only **29 one-seed first-owner opening roots**, and each original game was deliberately censored at 48 Store actions. It does not certify that the default bot chooses good actions, that its information usage is legitimate, that the Tool's later gameplay effects are correct, or that any alternate strategic line is dominated. This is source-root **mechanical execution evidence**, **zero competitively qualified matches**, and no demonstrated progress to the fixed-60 **99.5% win-rate target** until genuine complete, both-sided, fair matchup play becomes available.
