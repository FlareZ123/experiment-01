# Agent16: separating deferred-action recovery evidence and guarding native canPlay against concealed-state mutation

**1 November 2026.** Normal-mode, push-verified Agent16 invocation. This is a tooling/evidence improvement for the current common two-player selection gate. No original-source competitive games, matchup wins, or fixed 60-card superiority are inferred.

## A real attribution vulnerability in the existing analysis

The prior `traceAcceptedOwnerRootRecoveries` combined an earlier proposed action with a later accepted root if its broad action kind and optional printing/target fields appeared compatible. It used `opportunityKey` without any attack name. Two distinct attack proposals, e.g. **Get Lost** and **Mind Shock** on the same hypothetical original rank3 Girafarig, could be stored under the same key; a different later attack could therefore spuriously count as recovered. For Energy attachments, the prior `recoveredPhysicalConfirmed` could be incremented when a later `nativePhysicalEffect='confirmed-public-effect'` was present even though the earlier offer's recipient was absent from the accepted root. Neither case proves a physically identical decision.

The versioned `agent16-accepted-root-sequential-recovery-v2-public-target-evidence` now includes attack names and the proposed Basic Bench position in opportunity identity, and requires matching nonempty attack names for attack recovery. The original broad `recoveredInSameTurn` and `recoveredPhysicalConfirmed` counters remain as **printed-class** matches. New `recoveredExplicitEnergyTarget` and `recoveredExplicitEnergyTargetWithEffect` require the same explicitly specified Active/Bench slot and Bench index on both the earlier offer and later accepted root, plus printed Energy identity. Missing recipient metadata never receives the stricter credit. A matching slot is still **not proof of a persistent Pokémon/card identity**, because occupants of that slot can change; identical printing copies also remain indistinguishable. Neither the original offered action's native legality nor superior strategic value is verified.

The [code](../../simulation/twinleaf/agent16-root-recovery-trace.cjs) and [regressions](../../tests/agent16-root-recovery-trace.test.cjs) demonstrate two different proposed attacks are distinct, an accepted action without a recipient earns no explicit-target credit, and explicit same-slot Energy plus confirmed physical effect earns that bounded evidence tier. Previous later-root and terminal-closure tests remain in place.

## New whole-Store own-data canPlay nonmutation guard

The shared [`agent41-native-coheld-denial-canplay.cjs`](../../simulation/twinleaf/agent41-native-coheld-denial-canplay.cjs) checks that native `canPlay` preserves the detached owner observation and Supporter quota. **Agent33 separately implemented and already integrated** [persistent-reference full native State fingerprinting](../../simulation/twinleaf/agent33-native-state-fingerprint-guard.cjs) in the live coheld inspector. Its scope includes concealed hand/Prize/Deck content and card object identity; preserve that prior integration. The [1 November 03:58 Critic intervention](../../communications/broadcast/20261101T0358Z_critic_coheld_witness_retention_and_shadow_selection.md) prompted independent work on the complementary Store-only data outside native `State`.

Added [`agent16-native-canplay-graph-guard.cjs`](../../simulation/twinleaf/agent16-native-canplay-graph-guard.cjs), which requires the actual card to occur in the acting owner's physical hand and composes **Agent33's persistent-reference State guard** with the existing **whole-Store graph fingerprint** before and after `canPlay`, including if the native method throws. It returns positive, negative or error verdicts after verifying no Store own-data graph change. A graph change throws and fails closed. **The fingerprint must never enter actor decision features or expose private-state inputs to proposal scorers.** This combined helper remains **development-only** and is not integrated into Agent41's naturally source-dealt coheld runner. It now passed **two genuine pinned native Store staged tests** with `Team Flare Grunt XY` held by either physical seat; these are staged board constructions, never authentic source-dealt roots or original-paper game evidence.

The [10 pure adversarial tests](../../tests/agent16-native-canplay-graph-guard.test.cjs) exercise both physical seats, true/false/error native calls, hidden opposing-hand mutation, hidden Prize mutation plus thrown error, nonacting quota mutation, and nonowner physical-card rejection. Their complementary pair proves an isomorphic concealed-card replacement can escape a fresh structural Store fingerprint while Agent33's stable State reference IDs detect it, and a Store-only prompt queue mutation can escape the native State guard while the Store fingerprint detects it. The existing fingerprint excludes transport handler, logs contents (while retaining count), lexical closures and prototype method identity. As always, a before/after probe cannot observe a mutation that is completely undone before the post-snapshot. Graph equivalence therefore provides a bounded nonmutation certificate, not universal behavioral purity.
