# Agent 5: genuine Store actor-root decisions, rank-11 retrospective pilot

**20 October 2026. Evidence: compiled native execution; unqualified development policy.**

## Method

A reversible [actor-only root policy](../../simulation/twinleaf/agent5-owner-root-slice.cjs) intercepts **actual candidate-root decisions** made against the authenticated live Twinleaf Store. It consumes the detached, owner-visible actorObservation and metadata for the acting player's held and visibly attached cards. Abstract choices for Bench Basic, manual Basic Energy, printed attack or Pass become typed native actions dispatched to the actual Store. Speculative clone States cannot reach this policy. The original generic decision policy still controls all prompts and the opposing source player; these remain unqualified and are separately counted. Original classes are restored after each game.

Runner: [four-arm actual-Store rank-11 development](../../simulation/evaluation/agent5-owner-root-bilateral-native.cjs). It compares the unchanged rank-1 champion and New Moon fixed 60s against the exact published rank-11 Absol/Garbodor 60. Strict prompt validation and the opt-in both-seat paper Supporter quota are enabled.

## What the evidence supports

The root decision boundary has been exercised in a compiled, actual two-player Store. All 99 dispatched actions returned without a thrown exception. This is **not yet a validated card-effect count**: Store action submission must be reconciled against card movement, public board transitions, attack declarations and opponent continuation to establish mechanical outcomes. A first post-source candidate root was identified in each game, while all four source reply packets explicitly mark candidate reply competence unverified. No candidate declared an attack. Native terminal statuses are not competitive game outcomes.

## Remaining blockers

The actor-only policy handles only a small subset of paper-playable actions. It does not yet model Perfection or other copied attacks, full Energy provision, search/discard sequencing, Supporter and Tool optimization, gust/retreat planning, or owner-visible decision-making for compulsory prompts. Native prompt and opponent generic fallbacks preserve existing hidden-information and competence failures. Complete actor-only bilateral policy, source pressure and response, balanced actual starting order, fresh preregistered deals and tournament-clock validity all remain unproven.

**Qualified games: zero. No evidence supports a 99.5% game win rate or a final chosen fixed 60.** Follow-on validation should first attest the proposed Bench/Energy changes in the actual Store, then instrument why printed attacks never become realistic in the matched owner-visible states and replace critical generic prompt fallback.
