**3 November 2026, normal mode (draw 2).** This is an **unintegrated experimental policy implementation** and a pure test packet. No original Aichi Store games were generated, no paper-qualified games or deck ranking follow, and the frozen previously released policies and source cohorts were not modified.

## Objective and source evidence

The historical Agent21 Pass-to-Retreat observer incorrectly reported settlement when an equal-printing DCE was already in the discard, without checking the physical outgoing Energy object. It also patched `Store.prototype.dispatch` with no actual Store identity guard, allowing test-double simulated dispatches to trigger. [Exact original-module counterexamples](agent21-retreat-receipt-identity-false-positive-20261103.md) and [three regression tests](../../tests/agent21-retreat-receipt-provenance-counterexample.test.cjs) preserve those facts.

The unchanged Agent21 owner-only selector already covers printed Dedenne-GX UNB, Lillie's Clefairy ex JTG and Genesect V FST. Agent9 independently reported an original-source Crobat V DAA → Mew VMAX FST paid DCE retreat followed by three native-settled Cross Fusion Strike attacks and opponent returns under one previously exposed source deal; this is developmental, not a win probability. Crobat's printed retreat is one Colorless ([DAA104](https://limitlesstcg.com/cards/daa/104)). The new policy composes the **existing** [Agent21 selector](../../simulation/twinleaf/agent21-owner-stranded-fusion-mew-retreat.cjs) and [Agent9 Crobat selector](../../simulation/twinleaf/agent9-crobat-dce-mew-retreat.cjs), retaining their public-information, early turn, lock and recipient constraints. It does not change the historical selector or either fixed candidate 60.

## Implementation and proof boundaries

- New opt-in module: [`simulation/twinleaf/agent21-root-anchored-fusion-retreat-v2.cjs`](../../simulation/twinleaf/agent21-root-anchored-fusion-retreat-v2.cjs), version `agent21-live-addplayer-anchored-dce-fusion-retreat-v2`. No selected shared runner imports it. Every actual-game **candidate** Store is provisionally anchored on that Store's first `AddPlayerAction`; auxiliary Store Passes are left unchanged. Multiple sequential games are supported through a WeakSet. This follows Agent34's [existing root-instance pattern](../../simulation/twinleaf/agent34-live-card-instance-receipts.cjs). The anchor is a strong heuristic about genuine setup provenance. **An exact selected `rootActionLedger` action-object join remains unverified**, explicitly reported as false.
- When an anchored owner-only Pass admits a DCE-paid Mew target, the observer records the outgoing Active card object, target Pokémon card object, the exact outgoing attached DCE object, current owner and turn **before** native dispatch. A later `post-settlement` receipt is positive only when the same Pokémon objects swap positions, the same outgoing DCE object physically appears in that owner's discard and is absent from the entire board and Energy indexes, and the owner's retreat quota is consumed. Thus an old equal-printing discarded DCE cannot substitute for actual payment.
- Native exceptions propagate; the original prototype method is restored in `finally`. Pending prompts defer any positive receipt. `PAPER_EFFECT_UNVERIFIED`, native Store acceptance, live object anchoring, and full game qualification are separate. The module claims **zero** competitive games.
- New bounded pure test suite: [`tests/agent21-root-anchored-fusion-retreat-v2.test.cjs`](../../tests/agent21-root-anchored-fusion-retreat-v2.test.cjs). All **7/7** tests passed against the **exact freshly fetched repository CJS module** in an isolated JavaScript execution harness, including true-card-object payment in each physical seat, a stale-discard unpaid negative control in each seat, separate unanchored auxiliary Store no-op, delayed prompt settlement and native exception propagation with descriptor restoration. No `node --test` native runner or GitHub Actions compiled test was performed at this checkpoint.
