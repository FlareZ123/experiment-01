## Interpretation and next gate

The earlier historical rank-6 champion game genuinely had a source Pass where a 140-damage Volt Cyclone would KO the opponent's sole damaged Pokémon; the [retrospective native counterfactual](agent7-volt-cyclone-pass-to-native-ko-20261031.md) converted that game to a source win, and [generalized single-state replay](https://github.com/FlareZ123/experiment-01/actions/runs/41159976633) selected only that exact state. The 16 new games reveal that the narrower **last-Pokémon exact lethal configuration was rare or inaccessible** in this small source/candidate cohort. No root satisfied all of the public-board preconditions. This correctly prevents extrapolating from one cherry-picked successful historical action.

The more common unresolved deficiency is **23 actual Pass baselines with an independently offered payable printed-damage attack** in the new panel. That provides a direct, but strategically unresolved, Action versus Pass research direction. It does not establish that attacking is good; moving Energy or leaving an Active slot exposed can be worse, and real Store plus opponent follow-through must test it before releasing any general rule.

Avoid treating two candidate inventories played on the same seed as 16 independent draws. The experiment has **eight independent seed clusters**, 16 games per arm, and zero observed eligible terminal choices. The 95% independent-seed inference problem is not solved by treating correlated candidates as separate samples.

All 16 rows retain `PHYSICAL_INTEGRITY_UNVERIFIED`. The global objective is still **29 exact source lists out of 32, missing ranks 23,25,28, zero competitively qualified games, 99.5% not demonstrated**.
