# Agent 3: independent printed first-player Supporter exception census

**29 October 2026.** This is a reproducible card-text inventory supporting the bilateral owner-turn Supporter eligibility screen. It is **not** an independent format-legality or competitive-policy certification.

## Method

The repository-provided English card dataset under `resources/cards/en/*.json` was scanned in filename order. Every record with `supertype=Trainer` and `subtypes` containing `Supporter` was examined. A full, explicit text match for `If you go first, you may [play/use] this card during your first turn` was required; references to a first-turn *effect*, a first-turn *evolution bypass*, or a *go-second* bonus were excluded.

- Scanned **176 source JSON files** containing **1,167 printed Supporter records**.
- **10 printed records** contained the explicit first-player authorization, comprising exactly **3 distinct card names**: **Beauty** (three printings), **Carmine** (four printings), and **Team Rocket's Proton** (three printings).
- **34 Supporter printings** mention a `first turn` for some reason. Consequently, a naive substring check would overgrant the first-player exception.
- Wally's `You can use this card during your first turn` governs evolution timing; it lacks the explicit `If you go first` permission. Similarly, Jasmine, Dancer and Parasol Lady describe *go-second* first-turn bonuses. These wordings should not be treated as permission to bypass the ordinary first-player Supporter limit.

The complete sorted printing-level evidence is generated by [the deterministic scanner](../../scripts/aichi-first-player-supporter-exceptions.cjs); [pure regressions](../../tests/aichi-first-player-supporter-exceptions.test.cjs) assert the three expected names and reject Wally and go-second false positives. Locally, **2/2 Node 22.16.0 tests passed** against the supplied card pool. Both committed source/test blob hashes independently matched the locally tested bytes: scanner `a080921cf14cee65d682c8b35fdc34f235716381`; test `ac14d53a09a5c451f1c18c2ac18cd43d7900e141`.

## Why this matters

The currently shared [Agent 7 owner-root observer](../../simulation/twinleaf/agent7-owner-supporter-opportunity.cjs) uses exactly these three names in `FIRST_PLAYER_SUPPORTER_EXCEPTIONS`. The full-dataset census provides an independent source-level check of that **particular lexical gate** and protects it from silently accepting Wally's superficially similar first-turn phrase.

This is limited to the supplied text snapshot, and uses text wording as evidence rather than exhaustive ruling or legality verification. Bans, reprints, errata, interaction with player locks, Supporter quota, game phase, target availability, first-turn priority and resolution still require native Store/paper checks. The statistic `1,167` counts printed **records**, not unique cards or legal cards. In particular, no current candidate or rank-6/rank-11 opponent policy has been shown to select any of these three names when tactically warranted.
