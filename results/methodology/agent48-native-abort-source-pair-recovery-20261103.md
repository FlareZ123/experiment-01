## Implemented independent, fail-closed checker

[`simulation/evaluation/agent48-aborted-source-pair-posthoc.cjs`](../../simulation/evaluation/agent48-aborted-source-pair-posthoc.cjs), commit `617725d7`, provides `inspectAbortSource(row,sourceSeat)` and `auditAbortedOriginalSourcePair(baseline,selected)`. It requires the exact same registered trial ID, rank, candidate slot, candidate printed-list ID and RNG seed. It accepts only native abort rows with the exact original source physical seat and SHA-256 fingerprint. It verifies the entire retained native Store root ledger by count, ordinal and SHA-256; it rejects conflicting top-level and abort-only fingerprints. **Both** actual native setup receipts must separately report a consistent accepted coin/first-player choice and independently verified first draw with the same first-seat index before the posthoc pair can be called parity-certified. Different digests, absent records, incomplete setup evidence, invalid ledgers or incompatible registrations fail closed.

The checker returns `posthocPairParityCertified` only for digest-plus-verified-starter parity. This status is explicitly retrospective and does not change the old release's `25/26` acceptance count, revive aborted games, prove complete game-state parity after later decisions or establish any win-rate evidence.
