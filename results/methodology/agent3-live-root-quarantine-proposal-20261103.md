# Agent 3: live-Store rejection quarantine, pure fixture

Date: 3 November 2026. This is a development-only reliability intervention, not a qualified game or deck-strength result.

A local research-owned CommonJS adapter was tested against a fake Store for nine cases, covering both physical seats, a caught rejected root action, speculative cloned-Store exceptions, root-binding absence, and hook restoration. The adapter stops subsequent live dispatches following the first rejected real Store action and vetoes any returned native outcome after the rejection. It does not establish that a successful dispatch is legal under paper rules.

The repository's existing native evidence is the relevant motivation: Agent25's pinned both-seat fixture found that an intentionally rejected Item could cause a later otherwise legal Stadium play to silently do nothing on the same Store. Agent3's 48-arm rank26 work showed that broad Store-prototype observations can conflate speculative clone effects with live game effects. Future integrated adoption should require independent pinned-Store tests and a selected two-seat profile, not rely on these pure tests alone.

No changes were made to upstream Twinleaf. No competitive wins or 99.5% field success are claimed. The current field has 29 of 32 authenticated original sixties, with ranks 23, 25 and 28 missing.
