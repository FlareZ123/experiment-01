# Agent 1: numeric shuffle correction alone leaves eight original Issue25 native traces unchanged

**5 November 2026 | Native developmental causal negative control | 24 attempts, eight fixed registered physical source contexts, one deliberately isolated policy dimension.**

## Question

Agent3's planned v15 owner Wonder Tag true-versus-decline comparison adds both a genuine optional Lele Supporter search handler and the numeric `ShuffleDeckPrompt.validate` correction in treatment B. The pinned Twinleaf prompt validator calls ordinary JavaScript `.sort()` and compares the resulting lexically ordered integers to indices. That can reject legal shuffles with 11 or more positions. Does installing **only** the existing numeric correction, with the current v14 owner modal/Prize/Pokémon baseline frozen and Wonder Tag left declined, change the native public action history or abort status on those same eight known Issue25 original source trials?

## Registration and exact controls

The experiment is a retrospective replay of the unchanged eight `agent1-issue25-prechoice-input-custody-retro-v8-20261104` original trial identities (four rank6 Iron Thorns contexts and four rank11 Absol/Garbodor contexts). It uses original source printed inventories, the same candidate 60s, same physical seat schedule, the same source seeds and protected opening, unchanged player-specific owner modal acknowledgement, own Prize selector, Pokémon promotion selector, original printed-attack handlers and bounded root horizon. The same process-private Night Watch seed is shared across the three cohorts.

- **A:** Original v14 owner modal/Prize/Pokémon baseline; original pinned numeric shuffle validation.
- **B:** Identical baseline plus `withNumericShuffleValidator` wrapping the unchanged execution. No Wonder Tag affirmative handler.
- **A repeated:** Exact original A baseline.

The strict existing [v13 owner-input and public-root comparator](../../simulation/evaluation/agent3-issue25-v13-protected-prompt-aba.cjs) was reused without altering its acceptance conditions. The new [runner](../../simulation/evaluation/agent1-issue25-shuffle-validator-only-aba.cjs) includes a narrow injection seam for an independently tested wrapper-selection contrast; [pure test](../../tests/agent1-issue25-shuffle-validator-only-aba.test.cjs) and [native test](../../tests/agent1-issue25-shuffle-validator-only-aba.native.test.cjs) preserve every source trial, including abort and cap status. Manual CI input `shuffle_only_aba=true` is attached to an existing [Agent1 native manual workflow](../../.github/workflows/agent1-issue25-baseline-sham-v9-native.yml); no push-triggered experiment was added.

## Interpretation and future test

On these exact eight finite, retrospective protected-opening cases, correcting `ShuffleDeckPrompt.validate` alone did **not** change the chosen public roots or run dispositions. This is useful negative-control evidence against a *standalone* shuffle-validator explanation for subsequent A/B differences in these cases. It does not establish that the validator is irrelevant when **Wonder Tag is answered true**: an affirmative Supporter search can introduce a new required shuffle prompt absent from the decline-only baseline, creating a genuine interaction between the two interventions. The next causal comparison should hold the numeric correction selected across **all** A/B/A arms or separately verify that the first native root difference precedes any shuffle that could have been affected.

The original v15 proposed comparison is a joint treatment and must be labeled accordingly if left unchanged. The correction has already been independently native-tested under unlocked Wonder Tag affirmative search by Agent8; earlier [Lele entry guard composition](agent1-wondertag-iron-thorns-guard-composition-native-20261105.md) showed the established opt-in paper Ability-lock guard works under both installation orders and both owner seats. Such tests provide mechanism fidelity, not a competent source policy or a full playable matchup.

All field benchmark blockers remain: **29/32 authenticated Top32 original card-count inventories**, original ranks 23/25/28 missing, no selected single 60 and **zero competitively qualified games**; 99.5% remains an unsupported aspiration.
