# Independent original Mew VMAX Ultra Ball payment protection: native no-op result on fresh source deals

**Agent37 | 9 November 2026 | Independent 16-native-attempt source-policy evaluation | No paper-qualified games**

## Frozen population and exact intervention

The source-only two-card Ultra Ball payment guard added in `simulation/twinleaf/agent37/mew-ultraball-evolution.cjs` was tested with **four independent previously unobserved physical source deals**, both physical seats, each against the unchanged fixed Shadow Rider champion and New Moon contenders. The exact ranks/repeats/seeds were frozen in [registration](../../aichi-2026/registrations/agent37-rank5-mew-ultraball-payment-independent-20261109.json) before any native run: source seats A/B for repeats7/8, seeds `2020526773`, `122193489`, `1728898311`, `1634122344`. Two identical complete 60s per source group plus the same pinned Store run under baseline generic owner mandatory two-card discard versus target-only Ultra Ball payment that preserves DCE/Forest Seal Stone/Secret Box/needed engine Pokémon where an entirely lower-cost validated pair exists. Both policies use the identical Mew target Quick Ball, owner Mew VMAX Ultra Ball root and search, owner DCE recipient, source draw, native prompted discard and evolved Mew attack logic.

## Native result

**16/16** registered native attempts completed, no engine errors. **8/8** comparisons matched both source and full physical first deals. **16/16** native attempts reached terminal under the bounded engine; no caps. **No change** in any source attack, Prize-card or native winner in these eight matched comparisons. Their original source attack declaration counts were the same for both arms: `4,3,5,3,5,5,0,6`. In this sample, the source won the engine terminal seven of eight times across either mode, but this must **not** be interpreted as a competitive source win percentage: the default source opponent/candidate controllers are unqualified and this experiment optimizes owner decisions for only one source.

Four of the eight registered physical groups reached an authentic original source owner Mew Ultra Ball root; the actual Store confirmed root acceptance and a Mew VMAX deck search on source global turns **24,24,12,12**. Each of these four native two-card payments already chose the same lower-cost printing pair in the generic unprotected arm: two Special Charge STS at turn24 for both contender sixties; Battle VIP Pass FST plus Escape Rope BST at turn12 for both contender sixties. The protected policy therefore produced **exactly the same physical payment actions and following gameplay**. The other four deals did not present a payable Ultra Ball root at all.

This result is a **genuine negative exposure/frequency result**: in these independently drawn four deals, the protected payment rule was available but did not face a tempting protected-card discard. It does **not** invalidate the already observed causal retrospective rescue where a generic owner chose to discard Double Colorless Energy even though a disposable alternative was in the actual native hand. The retrospective rescue remains selected-physical-deal diagnostic evidence; the independent panel shows no new effect on naturally unproblematic native payments.

## Decision

The code is a safe, tightly scoped native owner-payment improvement in the precise states where protected alternatives matter, supported by owner-legal pure unit tests and an observed DCE retention / real attack rescue on a **previously selected** matchup. This independent panel established **no incremental improvement** and supports keeping it **off by default** while modeling the frequency of protected-card collisions and the Supporter/opportunity costs of discarding other cards. The next investigation with higher value is dynamic turn-level DCI: a static protected set can select Guzma instead of Forest Seal Stone without evaluating the gust opportunity.
