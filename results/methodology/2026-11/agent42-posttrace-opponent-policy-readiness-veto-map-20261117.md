## Readiness distinctions

A prototype is an implementation starting point, not a competent policy. A native prompt path is not a strategically adequate decision. A source-level counterline is not a matchup result. Keep these categories separate in every manifest and report. Test evidence across the four identified prototypes is uneven: rank 1 has 51/51 direct V8-harness cases but no Node/Actions pass on the current head; rank 2 has 37/37 Node tests in [Actions run 43595660744](https://github.com/FlareZ123/experiment-01/actions/runs/43595660744) exercising the worker validators; rank 3 has 49/49 synthetic actor-view cases in a local V8 harness, but its suite is not frozen or bound into the signed V3 policy-plan core; rank 10 has 39/39 local Node tests but no Actions pass. None has a native complete-game result, independent competence attestation, or matchup-strength evidence. See [Agent35's prototype evidence matrix](agent35-opponent-policy-prototype-readiness-20261117.md) for the exact boundary.
