**Agent37 research synthesis, 9 November 2026.** A deliberately constrained original-opponent policy investigation, retaining **one unchanged authentic source 60** and **two unchanged candidate 60s** throughout. These are paper Expanded source-pressure diagnostics with native Twinleaf receipts, **not** reliable match win-rate estimates, since the opponent decision policies, full current card-rules fidelity and tournament timing remain unqualified.

## What is actually achievable in a genuine Store

The source's structural plan can be decomposed into native owner actions with real payment and public state transitions:

`held Quick Ball -> play Item -> native discard one card -> own-deck prompt choose missing Mew V / Genesect V -> natural Mew VMAX evolution -> held Double Colorless Energy attach to correct Mew -> native Mew Ultra Ball if missing Mew VMAX -> native two-card discard -> own-deck prompt select offered Mew VMAX -> turn-eligible evolution -> Mew VMAX Cross Fusion Strike -> native copied attack effect and Prize resolution`.

Every arrow is conditional. Some components are parallel alternatives rather than a universally executable order, e.g., Ultra Ball to Mew VMAX is only needed when no Mew VMAX in hand/field. An apparent search graph can be rendered unplayable by losing the Energy to an actual discard prompt. Root category equality can conceal a different physically accepted Energy recipient.

These executable options, all **default off**, were added/combined in the shared `agent41-bilateral-v2-development.cjs` actor options:

- `actorMewGenesectQuickBallSearch`: source-owned Quick Ball native prompt requests missing Mew/Genesect; requires `actorOnlySingleSearch`. One fresh, settled extra Mew attack/Prize was demonstrated.
- `actorMewDceRecipientRoot`, `actorMewDceRecipientSourceOnly`: existing Agent26 ability; selected real Bench Mew instead of Active Dedenne for one identical DCE and same root hash. This did not independently yield an attack on the observed deal.
- `actorMewUltraBallRoot`, `actorMewUltraBallSearch`: new original source Mew VMAX Ultra Ball root/search; native own-deck search selected Mew VMAX, producing **five later settled Cross Fusion Strike attacks** on one trial and native source terminal in the treatment against the fixed New Moon candidate while matched control capped.
- `actorMewUltraBallPaymentGuard`: new source-only mandatory native two-card payment resolves actual Store-legal choices while preserving DCE, unspent Forest Seal Stone, Secret Box and necessary Mew/Genesect cards when possible. After public VSTAR use, FSS is discardable. Expired Battle VIP Pass (after global first two turns) and spent FSS are prioritized. In one selected actual source hand, preserving DCE **restored a subsequent genuine 210-damage Mew VMAX attack** versus the same source initial physical deal.

Never infer that any one option alone produces the full chain; it needs the rest of the common root and native opponent responses. The new additions modify research-owned `simulation/twinleaf/agent37/mew-ultraball-evolution.cjs`, `simulation/twinleaf/agent5-owner-root-slice.cjs`, `simulation/twinleaf/agent34-actor-only-root-policy.cjs`, `simulation/evaluation/agent7-canonical-actor-composition.cjs`, `simulation/evaluation/agent41-bilateral-v2-development.cjs` and `tests/agent37-mew-ultraball-evolution.test.cjs`. ## Reusable analysis principles

1. **Native prompt continuity matters.** A root Item play must be separated from the physical discard prompt, deck search choice, evolution eligibility, energy attachment, copied attack declaration, settled attack effect, and Prize receipt. Each can fail while the previous step genuinely happened.
2. **Owner-only context.** Scoring uses the owner's private hand, public boards/discard and actual prompted own-deck search, with exact physical native validator. Opponent private hand, unknown Prize identities and raw concealed deck ordering are never policy inputs.
3. **Opportunity cost dominates gross accessibility.** Ultra Ball requires exactly two cards, and generic duplicate-preserving discard can use the only DCE. Forest Seal Stone changes from nearly protected to dead after the VSTAR ability is exhausted; Battle VIP Pass is dead after the first-turn window. Decisions must be state-dependent.
4. **Compare accepted physical targets.** Identical root-action SHA did not imply identical Energy recipient. Use the Store accepted target sidecar plus public before/after boards to prove actual effects.
5. **Censored games give incomplete winner information.** A terminal in one arm against a capped control is a real continuation improvement; its causal native winner comparison is still unresolved, and any native terminal is unqualified for real paper win percentage.
