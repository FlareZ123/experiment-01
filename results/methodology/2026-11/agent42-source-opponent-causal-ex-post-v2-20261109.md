### The rank11 B counterexample changes the interpretation

Original native rank11 B, source physical seat **0**, global native turn **22**:

| Control source sequence | Search-treatment source sequence |
| --- | --- |
| Root 100: `AttackAction(Psychic)` | Root 100: `PlayCardAction(Quick Ball)` |
| Attack effects settled by root 103 | Root 101/102: source ChooseCards prompts; root 103: opponent ShowCards; root 104: source ShuffleDeck |
| Source turn ends | Root 106: `PlayCardAction(Crobat V)` |
| | Root 107: `AttackAction(Psychic)`, settled by root 110 |

Both pivot states show the same root 100 vs 107 distinction. Both baseline and treatment attacks actually completed. The attack took no Prize on this specific turn. Both policies eventually produced the same natural native winner, seat 0, for this deal. Quick Ball therefore **deferred** the source attack behind a search-and-Bench sequence; its changed first root did not establish that an attack was forfeited. Whether the search payment and Bench usage improved the source's overall playing strength remains unproven.

The observed source Quick Ball had an accepted Store root and native ChooseCards/ShuffleDeck sequence. The compact sidecar records `storeAccepted=true`, but it does not carry a complete independent owner-information and paper-printed-payment certificate. The generic checker deliberately reports `STORE_ACCEPTED_PAPER_PAYMENT_UNVERIFIED`, and it does not extrapolate competitive status from the native terminal.

## Concrete policy action

The reusable gate now distinguishes **a source-first action change** from **a settled attack delayed within the same source turn**. Source challenger evaluations should check both before treating a search-first sequence as stronger or weaker than an immediately available attack. Rank11 needs a prospective value-of-payment and target-quality comparison on genuine owner-visible states before increasing the sample size.

The gate additionally refuses candidate-seat first divergences, mismatched full and source physical deals, unmatched or prompt-only root changes, uncensored winner inferences from errors/caps, and unverified physical payment.

**Benchmark remains unchanged:** 29 authenticated original sixty-card inventories of the Aichi Top 32, three missing exact inventories (ranks 23/25/28), zero competitively qualified paper matches and no final selected deck or demonstrated 99.5% win rate.
