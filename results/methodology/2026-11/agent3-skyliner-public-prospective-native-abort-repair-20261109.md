## Game outcomes and explanation

All **16/16** candidate/source/full-deal fingerprints and true starter seats matched between arms. Ten pairs reached a natural terminal in both arms; **zero observed winner reversals** among them. The control produced **12 native terminals, 8 native candidate wins, 4 caps, 0 aborts**. The treatment produced **10 native terminals, 7 native candidate wins, 3 caps and 3 aborts**. Both arms had 16 attempts. Including all unmatched-terminal observations as censored, exact same-physical paired treatment-minus-control candidate-native-win count is bounded **[-5,+5]**. It cannot be identified as a win-rate improvement.

**Why treatment aborted:** The new owner-visible decision selector returned `kind:'skyliner-free-retreat'`. The shared actor converted that into a genuine `RetreatAction` at source original **rank7:9601:A** root96, **rank7:9602:B** root98 and **rank11:9601:B** root252. All three physically matched source deals and reported the same specific assertion: `rootPhysicalWitness` in `simulation/twinleaf/agent5-owner-root-slice.cjs` presumed any unhandled intent was an `'attack'`. The source aborted with `actual:'skyliner-free-retreat', expected:'attack'` before admitting any RetreatAction as live evidence. The treatment terminal deficit is therefore a **research adapter compatibility failure**, with no basis for interpreting the failed games as strategic losses. Native abort receipts contain the exact error, Store root, public pre-dispatch field and original source state.

**Corrective code shipped:**

1. Shared actor `simulation/twinleaf/agent34-actor-only-root-policy.cjs` now carries the selected owner-visible target's exact `printing` into the native Store intent alongside `benchIndex`, so the physical witness can identify the true replacement.
2. `simulation/twinleaf/agent5-owner-root-slice.cjs` now routes `skyliner-free-retreat` through the native **public Skyliner physical-retreat witness** (the same effective-zero-cost, Energy-preserving invariant used by the existing Clefairy-specific Skyliner retreat). This keeps the true Store responsible for legality and movement rather than bypassing the physical witness.
3. Added a pure regression in `tests/2026-11/agent3-skyliner-shared-owner-mobility.test.cjs` for the exact `skyliner-free-retreat` intent with a physically swapped Active/Bench identity, unchanged former Active Energy, used retreat turn, and absence of free Retreat when known public Ability suppression applies. The fixed contract [passes lightweight CI 42644979633](https://github.com/FlareZ123/experiment-01/actions/runs/42644979633).

The original 32-game registration and artifact are retained unchanged as failure evidence; their exact seeds cannot be reinterpreted as fresh after this repair. ## Interpretation

The first retrospective historical rank5 case remains a genuine native **Mimikyu → Latias Skyliner free Retreat → funded Trevenant & Dusknoir-GX Night Watch** winner reversal (different default-off mobility selector). This fresh four-rank run demonstrates a second actionable issue: **registering a new legal actor intent requires updating the native physical-action witness and preserving the exact recipient printing**. A policy that appears correct under pure chooser tests can still crash three real original-deck games if it has not crossed that transaction boundary. Every custom action class should have a positive native receipt and at least one negative suppressing-counterexample test before a large field claim.

Scope is native pinned Twinleaf development only, **zero independently paper-qualified games**, with no asserted 99.5% performance.
