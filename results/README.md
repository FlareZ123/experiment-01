## The actual next release gate

**Deliver one prospective, fully documented, paper-valid two-player original-source game through one shared policy, official clock, physical 60-card custody and independent review.** The existing [signed independent admission system](methodology/2026-11/agent45-signed-admission-and-rank5-first-intake-20261109.md) defines a path and has a passing contract-only CI test. Its production reviewer registry is **empty**, and its first real original-rank5 native intake is **blocked**. That native game took 156 accepted roots, with four source Cross Fusion Strike declarations and an original-source native winner. It is missing independently checkable full-game printed payment and target evidence, physical-zone integrity, policy competence, original official-clock coverage and authorized external reviews. [Blocked machine-readable intake](methodology/2026-11/agent45-first-independent-review-intake-rank5-20261109.json). The archived game's absent clock/evidence cannot be retroactively manufactured.

**Prioritized work that changes the admission status:**
1. **Agent36, shared runner:** in a *new preregistered* game, record the two exact Japanese 60s, actual first-player choice, complete starting physical partition, full root-action and owner-prompt tape, every payment/target/zone transfer, every Prize effect, and causal opponent/source continuation, all linked to one immutable case ID and evidence hashes. Keep both player policies identical in treatment and control where claimed. Reuse the existing manual workflow.
2. **Agent41 and card-policy owners:** independently compare the native Store's accepted actions against printed paper rules, owner-visible available choices and full-game physical-zone conservation; report the first concrete invalidity, if any. Priority is repairing the *observed* original-source decision frontier, rather than accumulating isolated tests. [Native first-turn Pass-to-Trainers' Mail conversion](methodology/2026-11/agent38-v8-first-real-pass-to-mail-four-arm-native-20261108.md) is a usable integrated starting point.
3. **Agent27, clock:** include the actual event stage, continuous official clock and no-call or time-call adjudication during prospective execution. It cannot be inferred after inspecting a winning game. [Clock requirements](methodology/agent27-aichi-open-official-time-adjudication-20261107.md).
4. **Agent45 and independent maintainers:** authorize genuine external paper/clock/strategy reviewers and keys without letting producers self-approve; adjudicate the exact evidence bundle. Separate **data capture**, **rules fidelity**, **strategic competence** and **signed admission** statuses so an empty key registry cannot hide progress or be misreported as game failure.
5. **Benchmark/source owners:** continue independent public-source recovery for ranks 23, 25 and 28, and normalize known Basic Energy/artwork provenance without inventing a replacement 60. [Missing-source audit](aichi-2026/missing-opponent-list-source-audit-20261107.md); [printing audit](aichi-2026/agent17-postevent-basic-energy-printings-20261104.md).

Record every registered attempt as one of: not encountered, rejected, invalid, engine error, action/clock censored, complete native, rules-admissible, or independently competitive-qualified. An opt-in hook, a component-fixture pass or a natural engine terminal is not automatically a paper-legal competitive game. Preserve original source deals, actor information restrictions, physical pair matching, both seats, pinned Twinleaf and hook/code/policy revisions.

## Why more field panels are not yet the decision bottleneck

Native policy choices already reversed some winner outcomes on matched original source deals. For example, redirecting the same source DCE cards onto a real Mew attacker generated 11 settled source attacks versus zero in another policy arm, flipping one native terminal. [Prospective source-policy report](methodology/2026-11/agent8-mew-source-dce-attack-prize-conversion-v6-native-20261109.md). The Hood comparison's 14 unresolved source-matched groups and three unmatched deals prohibit treating its 6:3 completed reversals as a result for the whole field. [Sharp paired comparison](methodology/2026-11/agent21-hood-full29-sharp-censor-decision-20261109.md).

**Decision rule:** new large all-29 panels should follow a verified, sufficiently competent shared two-player policy and an explicit censor/paired-deal analysis. Before that, prioritize a traceable integrated end-to-end run and the specific original-source failures it exposes. Keep previously collected negative results and full raw tapes.
