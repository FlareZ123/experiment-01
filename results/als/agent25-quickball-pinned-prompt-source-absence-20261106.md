# RETRACTION: Quick Ball prompt sourceCard absence conclusion was false

**Corrected 6 November 2026 | Agent25.** This file originally asserted that `ChooseCardsPrompt` could never expose `prompt.sourceCard` because its constructor does not declare that property. **This claim was wrong. Do not rely on the original report.**

The pinned native Store dynamically adds source attribution *after constructing the prompt*. In `ptcg-server/src/game/store/store.ts`, `Store.prompt` calls `stampTrainerPrompt`; when a Trainer is resolving, it executes `prompt.sourceCard = this.resolvingTrainer.trainerCard`. The native pin is `a9905a76a6c4103ba4b6cb9a49e86bad795c5c05`. The `ChooseCardsPrompt` class file is insufficient to determine the runtime prompt's properties.

The first genuine staged Quick Ball control [CI 42135872022](https://github.com/FlareZ123/experiment-01/actions/runs/42135872022) **failed its erroneous assertion** `prompt.sourceCard === undefined`: the actual result was a real `QuickBall` instance with the original `Quick Ball SSH` printing and physical ID `80031`. The four-arm canary terminated at this premature assertion and produced no valid four-arm artifact. This failure itself disproves the prior absence claim.

Consequently the original v1 `QUICK_BALL.has(prompt.sourceCard?.fullName)` check is **supported by the actual pinned native Store's Trainer prompt stamping**. The zero natural v1 chooser events observed in [CI 42133841156](https://github.com/FlareZ123/experiment-01/actions/runs/42133841156) cannot be attributed to a missing source field. The v2 supporter-staging classifier is an alternative potentially redundant source check, and its [CI 42135412393](https://github.com/FlareZ123/experiment-01/actions/runs/42135412393) also observed zero staged Quick Ball discard prompts in five nonexception natural games. Neither establishes how often Quick Ball was held or proposed as a native root.

**Revised method:** Assert *both* the true Store-stamped physical `sourceCard` and staged temporary `supporter` Quick Ball in native canaries, then use separate owner-only root-choice frontier data to determine why the original policy had zero natural prompts. Correct the separate v1/v2 interpretations without erasing exact original artifacts.
