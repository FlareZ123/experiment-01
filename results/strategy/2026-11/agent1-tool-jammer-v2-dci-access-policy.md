# Tool Jammer v2: singleton custody and access policy

**Agent 1 · 27 November 2026**

Tool Jammer v2 adds exactly one copy. The slot is only valuable if the policy preserves it when its unique action class matters.

## 1. Rank-15 DCI

Before the rank-15 Hooded BUS threat is permanently resolved:

- Tool Jammer is a **continuation-critical singleton**;
- New Moon has no Tool-recovery card;
- Hisuian Heavy Ball cannot retrieve a Trainer from Prizes;
- Rescue Carrier cannot retrieve a Tool from discard.

Therefore Tool Jammer's discardability should be near zero when:

- BUS Vileplume is still a live future Active;
- Stealthy Hood remains a live source resource;
- AOR Vileplume Item lock is established or likely to make Field Blower/Cologne unavailable.

Do not pay Secret Box's three-card cost or Reconstitute's two-card cost with Tool Jammer merely because it is not useful **this exact turn**.

## 2. When Tool Jammer becomes discardable

Tool Jammer's DCI can rise when actor-visible state proves its unique job is gone, for example:

- BUS Vileplume is permanently Knocked Out and no other relevant Active Tool target remains;
- the source's Hood copies are both known discarded/Lost Zoned with no recovery and no other important Active Tool exists;
- matchup does not use an Active Tool effect that materially changes the continuation;
- final-Prize line makes future Tool suppression irrelevant.

Do not infer hidden/prized Hood identities without evidence.

## 3. Pre-lock access routes

While Items are legal:

- **Adventure Bag** can search up to two Pokémon Tools, so it can fetch Tool Jammer plus Powerglass/FSS in one action when both matter;
- **Secret Box** can fetch Tool Jammer as its single Tool category, subject to its three-card discard cost;
- ordinary draw can find the singleton.

Adventure Bag becomes more valuable in rank15 v2 because its two-Tool search can preserve both the lockbreak Tool and the energy/search Tool package.

## 4. In-lock access route

After AOR Vileplume Item lock:

- Adventure Bag and Secret Box are unusable Items;
- Forest Seal Stone remains a Tool and can be attached to Galarian Articuno V;
- if Star Alchemy is not suppressed and Tool Jammer is in deck, Star Alchemy can search it.

Thus FSS is the principal deterministic in-lock Tool Jammer connector.

If FSS or Tool Jammer itself is Prized, HHB cannot recover it because they are Trainers. If Articuno V is Prized, HHB can recover **Articuno** only while Item play is legal.

## 5. One-Tool occupancy

Active Dusclops must be able to receive Tool Jammer.

If that Dusclops already holds Powerglass, Tool Jammer cannot be attached without a legal way to remove the existing Tool.

Therefore the policy must not automatically attach Powerglass to the Dusclops intended as the rank-15 Jammer host before the Hood state is resolved.

Prefer:

- FSS on Articuno V;
- Powerglass on a different intended attacker;
- Tool Jammer reserved for the Dusclops that can become Active.

## 6. Prize/access priors

A singleton Tool Jammer has a **10%** unconditional chance of starting in the six Prizes.

The two Dusclops physical cards both avoid the six Prizes with probability about **80.8475%**.

Those are pre-K1 priors, not state facts. HHB can repair Prized Duskull Basics but cannot repair Prized Dusclops or Tool Jammer.

This explains why v2 is a credible recovery package rather than a guaranteed lock answer.

## 7. Acceptance additions

- V2-JAMMER-DISCARD-PROTECT: rank15 Hooded BUS remains live; Tool Jammer is accessible; Secret Box/Reconstitute needs payment. Protect Tool Jammer unless abandoning the lockbreak line.
- V2-JAMMER-TOOL-OCCUPANCY: intended Active Dusclops already has Powerglass. Do not attach Tool Jammer illegally; compare a different host/Tool plan.
- V2-ADVENTURE-BAG-JAMMER: pre-lock Adventure Bag can search Tool Jammer plus one other Tool; value both roles rather than treating Bag as only Powerglass/FSS access.
- V2-FSS-JAMMER-PRIZED: K1 shows Tool Jammer itself Prized. Do not claim FSS can search it from Prizes; v2 loses the Jammer line until natural Prize recovery.

No competitive result follows.
