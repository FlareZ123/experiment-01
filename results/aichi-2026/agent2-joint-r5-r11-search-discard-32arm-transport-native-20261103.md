# Agent 2: selected joint rank-5/rank-11 owner-search and hand-discard transport fails to restore source attacks on exact physical deals

**3 November 2026 | 32 completed native development attempts | zero competitive game qualifications.**

## Decision

The first precommitted, controlled transport from Agent41's frozen original rank-5 Mew/Genesect and rank-11 Absol/Garbodor selected joint-v1 policy is **mechanically negative for attack competence**. Across the exact same eight original-source/candidate physical seeds and both fixed 60s, enabling the existing owner-only search prompt resolver, hand-discard prompt resolver, or both **produced exactly the same original-source attack declaration counts as the disabled baseline**. Original rank5 remained **0/4 native source attacks in each factor**, and original rank11 produced only **3 late Terminal Period declarations in one of four trials in each factor**; no source rank11 Claw of Darkness was declared. Thus those two existing resolver toggles, by themselves, are insufficient to restore original-source offensive competence under the frozen selected 92-option root policy on these deals.

This is a **same-deal test of prompt component transport**, with exactly the old selected policy otherwise fixed. It does not test the later root-level `bilateralQuickBallRoot` module from Agent41's separate 93-option joint QuickBall-v2 implementation. A no-attack observation cannot establish whether Quick Ball was physically absent, unaffordable, never proposed, or dominated by a competing legal action. Owner-root opportunity, full paper payments and opponent continuation remain qualification gates.

## Causal interpretation and immediate decision

With the old selected joint-v1 root choices held fixed, these two prompt handlers alone did **not** change the source offense at all on this particular same-deal matrix. This supports a narrower hypothesis: **the source bottleneck may be upstream of those prompts**, such as an unproposed owner-hand Quick Ball root, inconsistent resource recipient or missing Active promotion. The test deliberately cannot distinguish those alternatives; it also cannot prove that the two prompt handlers had zero live opportunities. Do not blindly enable either toggle in a newly selected policy solely because the component's isolated unit tests pass.

A separately pinned, later **93-option** Agent41 joint QuickBall-v2 policy adds an explicit `bilateralQuickBallRoot`, with new physical seeds and a different code revision. Its completed [native CI 41565964357](https://github.com/FlareZ123/experiment-01/actions/runs/41565964357) reports genuine rank11 Claw source attacks in some treatment arms, while several rank5 attacks occur even in its baseline on those different draws. Therefore a comparison of raw attack counts between joint-v1 and v2 would conflate random deal changes, new code and additional policy options. The appropriate next causal experiment transports that new **root proposal** onto the same old source physical deals, within an internally identical 93-option code snapshot, keeping prompt and payment controls separate when feasible.

There is still **no** chosen fixed winning 60-card list, **29/32** authenticated original opposing rosters (ranks 23,25,28 unknown), **zero paper-qualified games**, and **no** credible 99.5% game win-rate demonstration.
