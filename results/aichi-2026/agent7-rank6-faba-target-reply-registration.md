# Agent 7: retrospective rank-6 Faba prompt-targeting falsification registration

**Registered 19 October 2026 UTC before running the new compiled comparison.** This is a tactical opponent-policy test on the already inspected authentic 16 rank-6 Iron Thorns source deals, so it is not an independent sample and is excluded from matchup-strength denominators. The owner/public-board policy is deliberately narrow, with no modification to any source or candidate 60.

## Problem and falsifiable hypothesis

In the prior frozen replay ([full report](agent7-rank6-hood-source-removal-result.md)), one authentic source-selected Faba LOT action on repeat 8, source seat 0, seed `1381374318`, global source turn 19 did **not** remove the selected public Shadow Rider's Stealthy Hood. The pinned original Faba implementation shows a multistep prompt: choose Tool versus Special Energy versus Stadium, then choose an opposing Pokémon holding a Tool, and optionally choose the Tool card if several are attached. The pinned default `ChoosePokemonPromptResolver` scores Pokémon generically without a Hood-specific target priority. The previous report did not archive the exact Faba target prompt responses, so the reason for that specific no-reduction case remains a hypothesis.

This new intervention selects the **Tool option by value**, then a legal publicly Benched Hooded Shadow Rider VMAX (V if VMAX unavailable), then the Hood itself if the target has multiple Tools. Every decision is performed only while the acting source owns its original Faba prompt. It invokes the original compiled `prompt.validate` where applicable and returns an ordinary `ResolvePromptAction`. Unknown/unrelated prompts delegate to the original bot. Original Store dispatch, actual selected root action and physical Tool movement remain the evidence authorities. The intervention is not an approximation of generally optimal Faba usage; consuming the source Supporter can be costly.
