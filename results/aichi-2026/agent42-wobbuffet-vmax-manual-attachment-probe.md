**20 October 2026.** A narrowly scoped, reversible **development-only** adapter for the existing canonical common-policy runner. Zero competitive-qualified games. It has **not** been exercised against a pinned compiled Twinleaf Store in this incarnation.

## Direct prior evidence and hypothesis

Agent42's archived 24-trial Temple-vs-Iron-Thorns source-window panel ([source and artifact hashes](agent42-temple-thorns-source-window-panel.md)) yielded 3 Wobbuffet-selected openers, all on one correlated seed/seat schedule, and no completed Wobbuffet→charged VMAX→Max Geist sequence. In the rank24 seed 2026101854, actual source-dealt global turn12 owner-board observations showed two Benched Shadow Rider VMAX each with zero Psychic while Latias ex and other support Pokémon received attached Psychic. By turn14, Wobbuffet had moved off Active; no subsequent Max Geist was recorded. The existing archive lacks the actual root attachment action type at each observer snapshot, so this **does not prove** a legal ordinary attachment was available to redirect on that historical state.

**Testable intervention:** When a genuinely chosen native action already proposes attaching basic Psychic Energy from hand, and our Active Pokémon is Wobbuffet, prefer the Benched Shadow Rider Calyrex VMAX with the most basic Psychic attached among those with fewer than three. The intended mechanism is concentrating rather than dispersing three basic Psychic Energy onto one attack-capable VMAX while retaining Wobbuffet's Active lock until the attacker can replace it. This is a **proposed strategy**, not an established universal best move. It may deprive a support Pokémon of an important attachment, and it cannot conjure extra manual attachments.

## Added: pinned Underworld Door prompt recipient prototype

The [separate Underworld Door prompt wrapper](../../simulation/twinleaf/wobbuffet-vmax-door-prompt.cjs) addresses a second attachment route that the manual-attachment wrapper cannot touch. The pinned upstream Shadow Rider VMAX CRE source at revision a9905a76 generates an actual AttachEnergyPrompt with message ATTACH_ENERGY_TO_BENCH, player.hand as cardList, basic Psychic Energy filter, exactly one attachment, and Benched target semantics. It draws two cards after a successful physical assignment. Native AttachEnergyPrompt.validate checks Energy assignment structure but does not by itself certify every target; the wrapper also passes a proposed ResolvePromptAction to native SimpleTacticsAi.isValidAction. The authoritative live root Store must still be checked independently.

The wrapper acts only for our physical seat on an unresolved prompt matching this exact owner-hand/one-basic-Psychic/Bench shape, while Wobbuffet is Active and a Benched VMAX has fewer than three attached basic Psychic. It returns the original physical Energy Card object, selects the most-charged incomplete VMAX, and uses the original bot for all other choices. It can override the default prompt selection even when the existing resolver would cancel; **this is a proposed aggressive play policy**, not a universal rules obligation or demonstrated improvement.

[Five additional local mock/unit tests](../../tests/wobbuffet-vmax-door-prompt.test.cjs) passed (five pass, zero fail) across both physical seats, exact Card reference preservation, invalid native-result fallback, mismatch/blocked prompt safeguards, and opponent hidden-zone perturbation. Together with the seven prior manual tests, this is **12 locally passing unit tests**. There is still no actual compiled pinned Store result, no reproducible source-dealt improvement, and zero competitive-qualified wins from either adapter. The pinned source contract is verified by repository read, while runtime execution remains an open integration task.
