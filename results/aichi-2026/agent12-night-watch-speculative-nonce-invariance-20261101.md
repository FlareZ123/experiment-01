# Agent 12: Night Watch randomness must be independent of speculative bot prompt counts

**1 November 2026 | original research-owned Night Watch correction, bounded deterministic counterexample.** All game outcomes remain development-only; the correction and its tests do not certify paper randomness across a full real match or an official event win.

## Mechanism

At pinned research hook version `agent12-nightwatch-uniform-opponent-hand-positions-v1`, the random subset was sampled with a nonce equivalent to `String(prompt.id) + '|' + audit.structuralCandidates++`. Every structurally matching `SimpleTacticsAi.resolvePrompt` call increments this global counter, regardless of whether it belongs to the live physical Store or a speculative policy evaluation. Twinleaf's headless decision process can evaluate actions through hypothetical cloned Stores; Agent 39 independently measured auxiliary prompt dispatches in an original-Store study (see `agent39-volt-cyclone-common-prompt-portfolio-20261101.md`). It has **not** been demonstrated that any particular archived Night Watch selection itself had an auxiliary matching invocation.

This is a potential **causal reproducibility flaw**. The same genuine real prompt, physical hand, committed randomness seed and deck deal can select a different pair when an unrelated speculative prompt happens earlier. Exact evaluation of the original v1 SHA-256/rejection-sampling function, with four opposing-hand positions, fixed seed `fixed`, genuine prompt ID `7`, yields **[3,2]** for the first structural call (`7|0`) and **[1,0]** after one preceding hypothetical structural call (`7|1`). This exact small counterexample is an algorithm property, not a claim that a naturally dealt Aichi game exhibited it.

The revised `simulation/twinleaf/agent12-nightwatch-paper-random-chooser.cjs` derives the physical selection nonce from the public/native prompt identity `JSON.stringify([state.turn, String(player.id), String(prompt.id)])`. The historical global structural-call counter is preserved solely for observation. All physical indices remain generated from the independently committed SHA-256 seed, using rejection sampling and no preselection hand-card identity reads. Calls on hypothetical cloned states with the same public prompt signature now yield the same indices and cannot advance a shared sampling sequence.

**Limits:** A prompt ID's uniqueness within the relevant physical game/turn and exact printed Night Watch reducer attribution are **not** proven by this change. Distinct real prompts sharing the same actor/turn/ID nonce could receive correlated choices. The structural selector is still an opt-in policy adapter, and it does not by itself prevent other attack decisions from reading opponent-hidden hand information. Future certification must bind a unique physical live Store and initiating root ordinal to each printed Night Watch selection, independently audit the physical choice, and prove no reuse of the same nonce for distinct genuine random events. The shared Agent41 paper prompt portfolio still classifies Night Watch as **unverified**, correctly.
