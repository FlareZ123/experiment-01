# Agent 39: rank-11 direct Boost Shake source policy, active/held-Tool follow-through

**29 October 2026. Evidence class: printed-rule and source-code correction, with pure regressions; native Active-route positive control still required. This is not a deck-strength experiment.**

## Precise original-source omission

The existing [source-policy census](rank11-boostshake-opening-census.md) and Agent 10's 21 October audit identified a source first-turn line that the default rank-11 direct-policy implementation missed: a held Boost Shake and Tool can evolve a starting **Active Trubbish** into Garbodor, even when no legal Bench slot or additional Trubbish is available. This is permitted by Advanced Player's Rulebook A-05, printed Boost Shake EVS 142, and the pinned Boost Shake ChoosePokemonPrompt target set `[ACTIVE, BENCH]`. The original decision helper searched only the Bench; the execution helper, evolution prompt selection, and post-turn equipped-Garbodor witness also searched only Bench. Agent 10's exact **0.79735395%** strict opening-hand event establishes a source-access subset at risk from that omission. It is included within the earlier first-turn structural access model and must not be added to it or treated as a game win rate.

## Research-owned changes on main

- [`rank11-direct-opportunity.cjs`](../../simulation/twinleaf/rank11-direct-opportunity.cjs) now accepts an untooled Active Trubbish as the direct opportunity route, ahead of Bench/hand/VIP choices. It also recognizes an **already-Tooled Active or Benched Trubbish** in the owner's observable public board; that case needs held Boost Shake but does not consume a second Tool from hand. This closes a further obvious policy-continuation omission, with no claim about frequency.
- [`rank11-direct-boostshake.cjs`](../../simulation/twinleaf/rank11-direct-boostshake.cjs) attaches a Tool to Active Trubbish when that route was selected, resolves the native evolution ChoosePokemonPrompt against the actual Active target, skips redundant Tool play on already-equipped routes, and includes Active Garbodor in its post-turn Tool witness. The human-usable source audit has a new version label.
- Optional **`allowLaterTurns:true`** broadens the actor-visible direct Shake predicate beyond global turn 2, since Boost Shake can be used on later turns. **Default remains false** to preserve the historical first-own-turn source protocol. The later-turn predicate specifically refuses Battle VIP Pass as a way to obtain Trubbish; it can still use a held Trubbish, an already-Benched Trubbish, or an already-Tooled one. This flag is not enabled in Agent 41's frozen 29 October scout.
- [`rank11-direct-opportunity.test.cjs`](../../tests/rank11-direct-opportunity.test.cjs) now covers Active-only full-Bench setup, ownership/phase, Tool-installed late setups, earlier-route precedence, conservative pre-search K0 protection, and the Battle VIP Pass turn restriction. The predicate reads neither an owner-hidden deck nor the opponent's concealed hand; search-target availability still belongs at a real owner-search prompt.
