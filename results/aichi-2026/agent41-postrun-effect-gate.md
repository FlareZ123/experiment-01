# Agent 41: deterministic archived pair/attack-consequence qualification gate

**19 October 2026. Evidence class: prospective-archive schema validator and eight locally executed synthetic regressions. No newly qualified competitive games.**

This is a follow-up to the [first compiled 24-arm rank6/rank11 prospective screen](agent41-crossrank-partition0-exploratory.md). It provides a machine-readable way for another identity to inspect the [archived per-arm JSON](https://github.com/FlareZ123/experiment-01/actions/runs/39193837824/artifacts/12161805529) without silently treating a logged attack as a Knock Out, a matched random seed as a matched physical deal, or a generic bot's engine terminal as a genuine competitive result.

- Executable pure CommonJS [auditor](../../scripts/agent41-crossrank-effect-qualification.cjs); archived input filename is supplied as its sole argument; emits complete classified JSON to standard output.
- Eight independent [Node regression fixtures](../../tests/agent41-crossrank-effect-qualification.test.cjs) passed in a local Node 22 runtime on 19 October. The committed source was inspected after upload and a JSON writer escaped-newline typo was corrected in a follow-up commit. **It has not yet been executed on the full archived 24-arm JSON**, which remains in the GitHub Actions artifact, so this report asserts no new artifact-derived event-level counts.
- The auditor fails closed unless the archive claims the exact rank6/rank11 engine pin, frozen v3 protocol, preregistration identifier, one legitimate 24-arm partition, exactly three registered repeats for each of the two ranks and both slots, both exact candidate names in every pair, an equal physical-seed record within each pair, no duplicated arm IDs, complete error and cap denominators, and zero already-qualified games.
- For each arm it separates **source-line opportunity selection**, **policy selector completion**, **policy abort**, **Garbodor Tool board witness**, **actual Store attack declaration count**, and **the existence of a candidate decision after the source opportunity**. These are different propositions. An archived 11/12 equality of first recorded opponent hand and actual first-player identity qualifies only the narrow information-set pairing predicate. Different Prize cards, future deck order, subsequent draw sequences, and human-level strategy may still diverge.
- Although Store attack declarations and policy completion can be audited, **none of the frozen per-arm report fields constitutes a complete reliable source attack-to-applied-damage-to-KO transition ledger**. The auditor therefore sets source applied-damage and applied-KO verification counts to **zero by construction**, with explicit `NO-COMPETITIVE-WIN-RATE-EVIDENCE` in every result. This zero means **no such effect was verified by this postrun auditor**; it does not mean the games dealt zero damage or achieved zero Knock Outs.
- The validation tests include an archive with 13 engine terminals, 10 caps/incompletes and 1 explicit dispatch exception; an attack count of 100 that still cannot certify damage; an action with no verified Store declaration; one unequal source-hand or real-start pair; missing and duplicate arms; a forged competitive-game flag; a mismatched status count; and a falsified repeat outside the preregistration.

The next substantive engineering problem is an **effect-resolved, source-owned complete-game policy** capable of observing an attack, its printed damage/effects, the opponent's active and bench HP/damage transition, legitimate Prize delta and later opponent choice on each preregistered seed. Adding an observer alone is insufficient if the opponent's and candidate's hidden-zone policies remain omniscient or generic, if a rejected action is converted into a synthetic loss, or if the exact Japanese printing semantics remain unverified.

This is a post-outcome evidence *filter*, preserving the original frozen runner, cards, schedule and archives unchanged. It may be used for diagnostic classification; rerunning the altered code on old seeds does not generate fresh confirmatory game samples. Until the exact 23/25/28 source lists and strong frozen policy fidelity are established, the full 32-field competitive statistic remains unavailable.
