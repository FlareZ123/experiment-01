# Rank-10 source-ordinal Copycat decision audit

**Agent 7, 17 October 2026.** A scoped information-boundary and source-replay experiment for one archived rank-10 Regidrago source game. **Zero competitively qualified games**; no inference about the 99.5% target.

## Why the decision fork needs another control

The original [source-dealt Shred counterfactual](../../simulation/twinleaf/rank10-mimikyu-shred-source-fork.cjs), described by [Agent 38](agent38-rank10-second-turn-shred-opportunity.md), replaces a real `RetreatAction` with Mimikyu's `Copycat` using an actual `ChooseAttackPrompt` for discarded Dialga-GX's `Shred`. One source-game branch reversed the pinned engine's recorded winner in [compiled CI 38995971001](https://github.com/FlareZ123/experiment-01/actions/runs/38995971001). The result diagnoses a consequential decision on one physical shuffled deal.

The fork wrapper historically called `SimpleTacticsAi.decodeNextAction` before overriding the proposed retreat. That original selection can explore speculative game states and consume information or mutate transient state; other repository audits observe policy-time Store mutations. A matching archived pre-action zone hash alone does not prove that this preliminary bot call was inert or information-set-clean. A generic bot's choice may depend on its simulator's access to both players' hidden zones. This is an *unresolved possible dependency*, rather than a demonstrated leak in this exact action.

## Controlled alternative

The opt-in `rootActionOrdinal:215` mode in [mimikyu-turn28-shred-fork.cjs](../../simulation/twinleaf/mimikyu-turn28-shred-fork.cjs) counts dispatches on the authentic first-`AddPlayerAction` Store. At root dispatch ordinal 215, it checks the same bounded tactical prerequisites using the visible attacking and defending board, remembered opposing `Apex Dragon` announcement and its own discarded Dialga-GX. With `forceShred:true` it emits `AttackAction('Copycat')` directly, bypassing `decodeNextAction` for that specific decision. Its subsequent `ChooseAttackPrompt` still selects the exact printed `Shred` instance from the original discard. The unchanged control branch must independently show ordinal 215 was the opponent-facing `RetreatAction`.

All other root decisions still use the research bot. The ordinal is a deliberately fixed source-game position; this is a stronger diagnostic for one transcript and does not constitute a general competitive strategy.

The [source comparator](../../simulation/twinleaf/rank10-mimikyu-shred-source-fork.cjs), when run with `COPYCAT_ORDINAL_AUDIT=1`, produces an `ordinalSourceAudit` object comparing the original branch and the direct-ordinal branch: first root-action divergence, action 215 pre-dispatch zone and Card-history digests, existence of a real Shred selection, final winner and Prize counts, and byte equality of complete recorded match summaries against the original proposal-dependent Shred branch. If the source prefix changes unexpectedly, the experiment fails its assertions.

## Original bot source-state mutation audit: negative finding

An independent [compiled manual run 39006077523](https://github.com/FlareZ123/experiment-01/actions/runs/39006077523), source head `0870920`, invoked [rank10-turn28-bot-fingerprint.cjs](../../simulation/twinleaf/rank10-turn28-bot-fingerprint.cjs) against the **unchanged original fixed-seed game**. The read-only wrapper intercepted the **real** candidate's `SimpleTacticsAi.decodeNextAction` at root dispatch 215 immediately before `RetreatAction`. [Artifact 12090768770](https://github.com/FlareZ123/experiment-01/actions/runs/39006077523/artifacts/12090768770) records whole-State own-enumerable data-graph SHA-256 `f64981d5928c3f29d239543a485ad57960d8e47bd4cea68949b5ea6a05b3cf47` both before and after the bot call, **2,634 reachable graph nodes on each side**, graph node delta **0**, `graphMutatedDuringBotChoice:false`. The instrumented and uninstrumented source `runMatch` summaries are exactly equal; the observer did not change the winner or Prize counts.

This **refutes observable root State-data mutation for this one original turn-28 Retreat proposal**. It does not inspect the AI's hidden information accesses, intermediary speculative clones, closures/accessor side effects, policy RNG stream, all prior bot decisions, or later opponent decisions. It also means that the proposal-independent source fork's identical winner cannot be presented as evidence that a mutation bug existed at the original Retreat choice. It remains stronger evidence that replacing Retreat with the available source Copycat attack, under the same initial deal and directly selected action, was decisive in the pinned engine.

## Post-fork opponent-response audit

The [public response projector](../../simulation/twinleaf/rank10-copycat-response-ledger.cjs) records the following root decisions over the first five turns after the source-ordinal fork: attack announcements, copied attack names, active-Pokémon promotion choices, pass/retreat actions and Prize-count transitions. It deliberately removes hidden Prize identities, prompt source catalogs and any full private deck or hand contents. [Independent pure tests](../../tests/rank10-copycat-response-ledger.test.cjs) verify that a deliberately inserted unrevealed-card identifier is absent from its output. The source comparator exports both `counterfactualNextFiveTurns` and, when selected, `ordinalSourceAudit.nextFiveTurns`. Compiled CI validation for this extension is pending.

The source-ordinal bypass skips one generic bot call. It can therefore also alter the later consumption of policy-specific random numbers, even if the original decision did not modify the root game state. A different eventual winner must be interpreted alongside the immediate source fingerprints and action sequence, rather than attributed to any one kind of hidden-information exposure without additional controls.

## Evidence and limitations

- Fixed source: published rank-10 Regidrago versus rank-1 Shadow Rider, seed `4246551499`, candidate physical slot B, candidate actually first; no deck substitution.
- Pinned upstream Twinleaf revision: `a9905a76a6c4103ba4b6cb9a49e86bad795c5c05`; experimental rule and clone hooks remain opt-in, with their own validation gaps.
- New pure falsification tests under [tests/mimikyu-turn28-shred-fork.test.cjs](../../tests/mimikyu-turn28-shred-fork.test.cjs) exercise the exact-ordinal decision with a bot that **throws if consulted** and the mismatched-ordinal fallback.
- A separate bounded mock metamorphic test perturbs opaque hidden zone contents and retains the same Copycat/Shred decisions. That is limited to the provided mock source state and snapshot, since a full root-game information-set audit requires much more.
- The earlier pure hidden-zone test and the other source suite passed [compiled manual CI 39004397243](https://github.com/FlareZ123/experiment-01/actions/runs/39004397243), whose source head preceded the new ordinal mode.
- The first opt-in [CI 39004930338](https://github.com/FlareZ123/experiment-01/actions/runs/39004930338) failed its **wrong-ordinal negative unit test** before launching source replay. It found a real bug: after the ordinal check did not match, the hook still used the legacy bot-proposal override and forced Copycat. The intended source-ordinal isolation was therefore incomplete. Fix [`21e9679`](https://github.com/FlareZ123/experiment-01/commit/21e9679e6a58b27e8f336de2901ecea1d30f7694) returns the ordinary bot proposal outside the designated action number. This earlier red run must not be treated as a source-match failure, because its source test never executed.
- The second opt-in [compiled CI 39005718717](https://github.com/FlareZ123/experiment-01/actions/runs/39005718717), head `21e9679e6a58b27e8f336de2901ecea1d30f7694`, **passed the independent direct-ordinal source comparison**, the bounded hidden-zone unit controls and the source Shred fork. [Source-ordinal artifact 12091445617](https://github.com/FlareZ123/experiment-01/actions/runs/39005718717/artifacts/12091445617) (ZIP SHA-256 `1e1cbfc0fea8d90c920b25f292bf286379b1eb53b0f267c6632dec2dc2c5221c`) records root divergence **215**, pre-action zone digest `5a27a7fa4d3e9cbef465675b05cf2270f0550851f4cc579940a551c3ade70b4d`, Card-history digest `0faef7ac48c4f7a82c92413a3e0831b33bcc5ad162336e451d4d8ae4d6235548`, both byte-matched against unchanged control. The complete direct-ordinal `runMatch` summary was **byte-identical** to the original proposal-dependent Shred fork: simulated winner physical seat **1** (champion), 3/0 remaining Prizes (Regidrago/champion), **287** recorded main actions and global turn 38. Direct-ordinal source trace contains **289** root Store dispatches including player registration. These are one deterministic source-game outcomes, and the actual-opponent policy is still unqualified. The full overall workflow remained running after this stage at the point of inspection, with unrelated later stages not yet confirmed.

Even a successful direct-ordinal comparison leaves source reducer-closure semantics, full paper rules, opponent competence, unsupported card effects, information-set safety of all other bot actions and multiple independent seeds unresolved. **`sourceReplayMechanicsVerified:false`; `qualifiedForCompetitiveInference:false`.**

## 17 October compiled follow-up: source-decision isolation and projector gap

[Manual compiled CI 39006077523](https://github.com/FlareZ123/experiment-01/actions/runs/39006077523) finished successfully. At the original, unchanged candidate turn-28 root-Store decision (dispatch ordinal 215), the original bot chose `RetreatAction`. Whole-State enumerable graph fingerprints before and after that precise `decodeNextAction` returned the same SHA-256 `f64981d5928c3f29d239543a485ad57960d8e47bd4cea68949b5ea6a05b3cf47`, with 2,634 nodes in each. The instrumented and uninstrumented `runMatch` summaries were identical. This is a scoped **negative result for observable mutation**; it cannot establish information-set safety, clone/closure fidelity, or the quality of the choice.

The same compiled run's direct-ordinal output reproduced the prior controlled `Shred` selection and source winner reversal. However, the *new public response projector* emitted `selectedSource:null` and `selectedCopiedAttack:null` for the actual turn-28 `ChooseAttackPrompt`, `prizeCountSelected:null` for the actual Prize prompt and empty `promotions` on the recorded promotion prompt. Its unit tests passed, but the source output shows the projection is **not yet an adequate proof of prompt-choice completeness**. The attack identity remains independently observed in the fork hook and the staged/compiled attack regression. A follow-up must inspect per-event `attackChoiceCaptureError`/`slotChoiceCaptureError` and the actual archived action-reference envelopes, then make real-source prompt-selection assertions fail closed without exposing hidden Prize identities or source catalogs.

[Manual CI 39006380129](https://github.com/FlareZ123/experiment-01/actions/runs/39006380129) also finished successfully: the opponent-own turn-29 perspective capture ran twice with different telemetry seats, asserted the complete `runMatch` summary was unchanged, and archived artifact `12090634957`. The JSON snapshot was not printed in the CI log; its detailed own-hand, board and attack-opportunity contents have not yet been independently interpreted. The earlier root response trace records Retreat then Pass on turn 29. It is **not established** whether that Pass was forced by resources, legal action constraints or weak decision ordering.

**Qualification status is unchanged:** one source-dealt deterministic policy-sensitivity witness, zero competitively qualified games, and no supported full-field win-rate estimate.
