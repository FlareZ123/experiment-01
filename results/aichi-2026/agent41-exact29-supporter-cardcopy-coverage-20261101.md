## Method and source

Counts refer to *physical copies* across those 29 source 60s, not sampled draw frequency, available plays, or competitive outcomes.

The source-dependent census was obtained from the live GitHub roster. All original source ranks remain in the denominator. The research card database is a classification resource; this is no new format-legality judgment.
