# Agent 19: fresh prospective source Snorlax backup threat policy, preregistered

**21 October 2026, before first dispatch.** The previous 12-pair [source Bench-reservation trial](agent19-snorlax-bench-preservation-native-results-20261021.md) has already disclosed three rank3 solo starting boards and two earlier opponent native terminals when backups were suppressed. Those deals are **excluded** from this independent test. The new source policy is designed after that evidence, but the **new 24 physical-deal seeds and all policies are frozen before outcome inspection**.

## Falsifiable purpose

Can a conservative source-owner/public-board policy permitting ordinary Backup-Basic Benching once an opposing in-play Pokémon has any visible attached Energy remove some of the unconditional-solo tactical vulnerability while preserving earlier Block restraint in unthreatened states? Does it produce any actually different native Store roots on original registered source lists? This is one narrow proposed ingredient for eventual competitive source-opponent decision competence, and the opposite tradeoff is possible: energy alone does not prove knockout readiness, and a Bench can be exploited by gust.

No opponent hands, opponent deck, future draw, hidden Prize identities or randomized action scores may be consulted by this new policy. The source code inspects only the opponent's visible Active and Bench cards' attached Energy lists. A ready zero-Energy attacker (attack-cost bypass), a switch/energy-acceleration line, tool interactions, or an attacker with insufficient damage can invalidate the heuristic. This is **not a safety certificate**.

## Frozen experiment

- Exact original Aichi rank3 Haruto Miki and rank7 Hiroto Fuji 60s as source players, unchanged original rank1 Shadow Rider reference 60 as challenger.
- Existing explicit resolution permissions for equivalent Basic Energy, Basic Energy mirror printings and documented Japanese promo hooks; source/printing hashes recorded. No new card substitution.
- Pinned Twinleaf SHA `a9905a76a6c4103ba4b6cb9a49e86bad795c5c05`; research-owned opt-in wrapper only, no vendor mutation.
- Fixed `SEED_BASE=2026102125`; `deriveSlotSeeds(SEED_BASE,'pilot',rank,repeat)`, seed slot **B** for source seat A and seed slot **A** for source seat B.
- **24 physical deals:** ranks 3 and 7, each source in actual physical seat 0 and 1, repeats 0 through 5. Actual first player determined only by live draw event. Each physical deal receives **three arms**, or **72 planned bounded attempts**.
- All three arms keep `snorlaxSoloOpeningSeat`, `snorlaxSoloDeclineOptionalBench:true`, `snorlaxRetreatStartCorrection:true`, isolated policy RNG, strict prompt checks, actual starting-board capture, full public root ledger and final public board. Each has **100 genuine native root actions maximum**.
- Arm `ordinary`: plain `PlayBasicTactic`. Arm `unconditional`: suppress `PlayBasicTactic` whenever source Snorlax PGO is alone Active. Arm `public-energy`: apply that suppression only while **no opposing in-play Pokémon has publicly attached Energy**. Every other headless flag, deck identity, game seed and owner policy remain equal.
- The public-energy guard is activated only on the designated source player in the real `runMatch` state and is intentionally separate from historical unconditional control. No other code paths in the candidate player are modified.
