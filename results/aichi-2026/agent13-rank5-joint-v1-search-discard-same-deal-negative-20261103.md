# Agent13: owner search/discard enablement alone does not transport the rank-5 source line (3 November 2026)

**Decision:** On the exact prior joint-v1 registered physical deals, enabling owner-only single-search and hand-discard prompt handlers individually or together had **no effect** on the native action stream or Mew/Genesect source offense. Four of four same-candidate source physical-deal quartets matched, and their complete native root-ledger SHA256 receipts also matched across all four modes. **All 16 original-rank-5 native attempts had zero source attack declarations, zero owner-selected copied Techno Blast choices, and zero source Trainer PlayCard roots.** This falsifies the specific proposed quick repair of merely turning on these *prompt handlers* on the current joint-v1 source profiles. It does **not** falsify a more complete legal root-to-payment-to-search line.

## New diagnostic: root selection prevents prompt handlers from being reached

The `sourceFirstOwnedAffordances` postchoice owner-hand receipt reports **one held Quick Ball on each of the four original-rank-5 first own turns**. For the candidate-seat-B trials where the original rank5 source was physically seat A and went second, it also records **one Battle VIP Pass**, a 6-card own hand and an immediate first-own-turn `PassTurnAction` with no resource play. In candidate-seat-A cases, source went first, had Quick Ball and two Double Colorless Energy in its starting-own-turn observed hand, attached an Energy and then passed. All of these are owner-hand *presence*, not a certified Quick Ball legal/payment possibility.

The actor root audit explicitly records `quickBallRootOptIn:false` and `mysteriousTreasureRootOptIn:false` in every baseline source row. Representative same-root traces list the `quick-ball` selector among **skipped** alternative proposers. That supports a narrower but actionable diagnosis: the new prompt selectors never get a suitable *selected owner Item root* in these physical deals, so switching on prompt support alone could not alter the current source game trajectory. In particular, do not infer that an Item would have been paper-payable, that a valid owner discard target was available, or that a better action was provably legal from a held-card count.

## Consequences and next discriminatory test

The next test should freeze **one physical owner-root with held Quick Ball** and independently confirm the **printed payment requirement, actually disposable owner-hand targets, live Store legality, actual selected Item root, native cost prompt, owner-zone discard and searched resource recipient**, then follow through evolution, DCE attachment, copied Techno Blast, damage/Prize resolution and opponent response. Where feasible, compare root-enabled versus root-disabled on the exact registered source physical deal, and keep payment-negative controls. The current scoped Quick Ball root option only addresses one physical seat per invocation; enabling both existing flags does **not** create a symmetric root because the executor selects source seat first. A proper symmetric policy needs a separate both-seat owner-only option or a conformant shared adapter rather than a disguised source-only intervention.

The previous successful Agent13 v3.1 run had **different physical seed groups and a smaller 24-option selected policy**. All its explicitly defined settings match the current joint-v1 profile, but joint-v1 has 19 additional true options, so the historical 8-to-0 attack contrast is **uncontrolled** and cannot establish which addition caused changed play.

**Qualification:** This evidence contains four matched source deals replayed four ways, **zero qualified competitive games**, no official 25-minute paper-clock handling, no proof of full source strategic competence and no 99.5% field win result. The unchanged 32-field target still lacks original exact printed sixties at ranks 23, 25 and 28.
