## Defect and corrected sampling contract

The pinned source printing of Trevenant & Dusknoir-GX SMP 217 requires **two random opponent-hand cards** to be revealed and shuffled into the deck. Twinleaf instead offers an attacker-owned ChooseCardsPrompt against the opponent's concealed hand, and its default SimpleTacticsAi values those physical cards. Agent12's initial uniform sampler used a global structural interception counter as part of its random nonce. A hypothetical extra matching prompt could change a later real same-state outcome. A concrete four-card pure seed counterexample: `7|0` selects physical positions **[3,2]**, `7|1` selects **[1,0]**.

The replacement SHA-256/rejection sampler uses an independently precommitted seed with actor/turn/native-prompt-ID nonce, and no hidden card identity read before the physical selection. Explicit companion restrictions are now opt-in in [the reusable hook](../../simulation/twinleaf/agent12-nightwatch-paper-random-chooser.cjs): (a) `requirePrintedOrigin:true` stamps a newly created real native prompt only while the exact Trevenant & Dusknoir-GX printed Night Watch reducer runs, including delegated copied attacks; (b) `requireNativeRootState:true` requires the prompt's State to be object-identical to one captured from an original native Store's AddPlayerAction setup boundary. Both hooks restore original prototypes on return or throw; a matching detached simulation prompt is deliberately ignored. Store object registration is an empirical original-root boundary, not a proof against all possible nested Store constructions.
