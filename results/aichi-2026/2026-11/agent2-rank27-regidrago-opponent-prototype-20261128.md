## Source-real decisions added

- **No rank-10 phantom cards.** The policy refuses to play a card not present in rank 27's exact 60. Unlike rank 10, rank 27 has no Battle VIP Pass, Squawkabilly ex, Faba, or Hisuian Goodra VSTAR; it *does* have Net Ball LOT 187, Eldegoss V RCL 19, Crobat V DAA 104, four Quick Ball FST 237, Path to the Peak, and Noivern ex PAL 153. A source-safe rank-10 heuristic is used only as a bounded fallback.
- **Dragon-vs-Grass search and recovery.** Net Ball LOT 187 cannot fetch Dragon-type Regidrago V. It *can* search **Eldegoss V RCL 19** (Basic Grass), enabling `Happy Match` to recover an existing discard Supporter when there is a free Bench slot and no visible Path to the Peak or Pokémon-play lock; otherwise it prefers a Grass Energy. This branch was added after the first report upon checking the exact Eldegoss and Net Ball source texts. Quick Ball searches only Basics; Mysterious Treasure searches only Psychic or Dragon Pokémon; Ultra Ball searches any Pokémon. Their card-combination discard-vs-search phases are distinguished by the host's public `sourceZone`, not free-text descriptions, and the discard path protects a last unavailable Regidrago V and the ACE SPEC.
- **Setup and funding.** Prioritize actual Regidrago V and evolutions, donor-bearing Battle Compressor, legal optional Budew lock, and offered Legacy Star / draw Abilities. Native-offered Apex Dragon is not prioritized without at least one observed real Dragon payload in the actor's own public discard.
- **Attack prompt custody.** Choose only a native-offered, actor-owned, actor-visible, discard-sourced Dragon printing whose exact attack is present in the public choice. Timeless-GX selection uses the shared Apex evaluator and the public GX-used flag; Covert Flight / Dominating Echo have explicit, heuristic matchup circumstances. This does **not** constitute a native copied-attack execution witness.
- **Extra-turn KO correctness.** Raihan is never enabled by Twinleaf's potentially stale `pokemonKnockedOutDuringOpponentsLastTurn` Boolean alone. The policy requires a turn-stamped owner-aware `priorOpponentTurnKO.turn===opponentLastTurnTurn` public receipt; the current main V3 host does **not** emit that receipt, so the route remains safely unavailable there.
- **Whole-game prompt dependencies.** The development worker answers typed engine opening-Basic / optional Bench / going-second / mandatory promotion / ordinary hidden-Prize-slot selections, with token-only access; source-unknown prompts abstain, and one-card ChooseCardsPrompt uses the protocol-required `select-choices`, not `select-choice`. An optional no-matching-donor search selects a genuinely offered `empty-selection` token, not invalid `select-choices:[]`.

The pinned Twinleaf classes use numberless `fullName` values such as `Regidrago VSTAR SIT` and `Net Ball LOT`, while the authentic Aichi 60 includes a printing number. This worker now derives a **collision-checked, exact-source-only** runtime alias for each of the 37 source entries. `Regidrago VSTAR SIT` normalizes to the known source `Regidrago VSTAR SIT 136`; an explicitly wrong number such as `Regidrago VSTAR SIT 201` still fails closed. ## Two concrete attack-line repairs added after the initial prototype

The native root action frontier presents a Basic or Special Energy attachment as `kind:'play-card'` with an actor-owned Pokémon target. This worker now scores those actual token-bearing actions, measuring the exact **Grass, Grass, Fire** attack cost. **Double Dragon Energy ROS 97 contributes two flexible Energy units** on an actual Regidrago V or VSTAR; it is not equivalent to one Basic Energy card. It prefers finishing an already powered attacker and rejects wrong owner, target, unrecognized type, or surplus energy on a fully funded attacker. The Crispin root heuristic now checks **attacker** energy coverage, rather than the total number of attached cards scattered across one's board. Authentic two-Dialga-GX rank27 source multiplicity also exposed a different path error: selecting both physical Dialga copies in Battle Compressor would crowd out a distinct attack payload. The worker now uses a distinct-printing donor selector, selecting Dialga/Dragapult/Noivern rather than two Dialgas, while respecting Native-selected deck cards and optional empty selection.

The same pinned Regidrago V SIT135 source opens a mandatory `AttachEnergyPrompt` after **Celestial Roar** mills Basic Energy. This source is *not* Underworld Door, the only AttachEnergyPrompt accepted by main's current projector, so a policy without a bridge cannot complete the attack. A new [strict source-bound Celestial Roar bridge](https://github.com/FlareZ123/experiment-01/blob/agent2/pinned-ko-prize-engine-continuation-20261128/simulation/evaluation/2026-11/agent2-rank27-celestial-roar-attachment.cjs) is available on the same **unmerged, default-off** research branch as the KO/Prize continuation. It constructs **one composite opaque actor choice** representing all 1–3 mandatory Basic Energy cards from the actual native temporary CardList, validates the raw transfer using the pinned validator, and reveals no incidental non-Energy card identities. Branch-local native-shaped [tests](https://github.com/FlareZ123/experiment-01/blob/agent2/pinned-ko-prize-engine-continuation-20261128/tests/2026-11/agent2-rank27-celestial-roar-attachment.test.cjs) pass **7/7** local V8 groups across both seats, including host→rank27 worker→strict protocol, exact SIT135 provenance, cardinality and secrecy. The pinned engine's separate Celestial Roar **Special Energy semantics** bug has an existing paper hook owned by other agents; this adapter deliberately implements the observed pinned **Basic Energy** prompt and does not purport to repair the vendor bug. No native same-Store game was run.

## Matchup-specific lock and extra-turn adjustments

Source-backed actor-visible lock checks now prevent the **Net Ball→Eldegoss→Guzma** line from being preferred when its immediate payoff is inoperative. These include active **Iron Thorns ex TWM77** (Aichi ranks 6/24/29, Initialization locks Eldegoss's Rule Box Ability), active **Wobbuffet PHF36**, **Stoutland BCR122** (Sentinel prevents playing the recovered Supporter), **Galarian Weezing RCL113**, **Silent Lab PRC140**, and **tool-attached Garbodor BKP57 or LTR68**. A Tool-less Garbodor does not activate the modeled Garbotoxin lock. The checks are conservative, not a complete ability-effect matrix: a complex counter-lock such as Ability nullification of the locker could make the source line live in states that this heuristic rejects. Freshly benched Eldegoss cannot be preequipped with Stealthy Hood, so an otherwise active lock invalidates its entering-the-Bench recovery.

**Raihan EVS152** requires an actor-owner-bound **Agent47 certified v5** KO receipt. A last-opponent-turn stamp is not inferred from `globalTurn-1`: an opponent may take an extra turn (making an old KO stale), or the actor may take a consecutive extra turn (keeping an older opponent-owned KO fresh). This worker now requires exact v5 receipt version, actorSeat, current turn, `opponentLastTurnOwnerCertified===true`, and `priorOpponentTurnKO.turn===opponentLastTurnTurn`. Current main v3 receipt cannot supply this and deliberately leaves Raihan unavailable. The underlying v5 producer/Store legality-fence solution is **already implemented by Agent47 on an unmerged branch**; this consumer does not assert it has been integrated or admitted.

**Preferred paper Celestial Roar route:** Agent3's already native-tested `simulation/twinleaf/regidrago-celestial-roar-paper-custody-hook.cjs` repairs original pinned Celestial Roar physical-card loss and **eliminates the unnecessary AttachEnergyPrompt entirely**, attaching all Energy cards (including compatible Special Energy) to the original active Pokémon. The separate default-off Celestial prompt bridge here is only useful for diagnosing/replaying the **unmodified pinned, Basic-only** engine and must **not displace** that established paper-rules hook. Its branch tests do not increase tournament-performance evidence.

## Final-Prize gust lines that beat an otherwise legal attack

Source rank27 includes both **Prime Catcher TEF157** and **two Guzma BUS115**. Pinned Twinleaf card implementations provide sequential choice prompts that first select an opponent's Benched Pokémon and then require switching the actor's Active to an actor Bench Pokémon (Prime Catcher and Guzma have distinct Trainer costs, but the same two physical positioning constraints). An otherwise simple one-card search graph tends to miss the second positioning constraint and consume the gust without any legal attacking recipient.

The rank27 worker now explicitly seeks a **one-Prize remaining, source-real** line when Dragapult ex TWM130's `Phantom Dive` payload is already in the actor's visible discard, a second **Regidrago VSTAR on the actor's Bench has exact GG+F payability**, and a real opposing Bench Pokémon is within **200 remaining HP**. It prioritizes Prime Catcher (480), or Guzma (465 when Prime is unavailable), over an otherwise offered undirected `Apex Dragon` attack (420). The two native `ChoosePokemonPrompt` branches score **opponent** damaged target versus **actor** ready attacker separately. Prompts mixing both owners, targeting a non-Bench zone, or sourced from a wrong printing abstain. Synthetic 29th/30th regression groups verify both seats, actor/opponent choice protocol, no donor, no ready attacker, no final-Prize, no vulnerable Bench target, and invalid target. Source cards and actual pinned `guzma.ts`/`prime-catcher.ts` were inspected directly; this is a **candidate decision-policy line**, not a native execution witness.

**Known limitations:** 200 nominal damage does not imply a real KO through all protective effects, attack-blocking conditions, Weakness/Resistance, or opposing control; the worker is not a full damage simulator. The root's input is only a host-offered legal action, not evidence that any concealed card is available. A complete valid final-Prize win is not demonstrated until an actual pinned Store trace with the owner's frozen policy/fixture authorization shows the gust target, own switch, copied attack and Prize collection in order.

## Reproducibility and evidence boundary

Local isolated V8 CommonJS execution loaded the *actual checked-in* rank-10 helper, Apex-attack evaluator, Phantom Dive allocation helper, rank-27 worker, shared strict Agent49 protocol, and test source from GitHub. **30/30 test groups passed** across physical actor seats 0 and 1. Test cases include the exact 60, role/seat/version mismatch, wrong-rank card rejection, source-real opening/evolution, prior-Dragon/absent-Dragon Apex action, stale-KO Raihan, own Legacy Star versus Path, supported/forged Apex prompt targets, Net Ball Grass vs Dragon, Battle Compressor donor set, GO_FIRST/initial/optional setup, promotion/Prize selection, and native selection/empty-selection shapes. This is in-process constructed-observation evidence, **not** pinned native Store compilation, CI, whole-game play, opponent strategic competence, or a valid Aichi matchup.

The shared strict `validatePrompt()` and `validateDecision()` were directly invoked on a real card-combination single-result request, an Apex one-attack request, an engine starting-Basic multi-select, and an optional empty-selection search, a Net Ball→Eldegoss support-recovery branch, source-typed Quick Ball discard/search, and Mysterious Treasure typed search. The one-card search initially failed the strict contract and was corrected before reporting 30/30. No fixture, original source list, frozen candidate 60, core V3 runner, or vendor Twinleaf code was changed.

**Not yet admissible:** host registration/manifest update by the designated owner; exact-source deck installation and synchronized request schema; native-tested prompt provenance for copied Apex→Dragon attack, attaching Regidrago Energy, tool/Ability lock and on-enter Bench chains, full uninterrupted gameplay policy coverage and review. The current worker is not a proven competitive opponent; it has deliberately conservative fail-closed routes and a rank-10 heuristic fallback. The published Aichi roster still has 29/32 exact lists, the complete 32-opponent *policy* panel remains incomplete, and **0/32 qualified Aichi matchups and no demonstrated 99.5% field win rate** remain unchanged.
