## Decision-relevant conclusion

A small, **default-off, both-seat actor-only** copied-attack chooser correction can replace a native no-payoff self-copy of Mew VMAX FST's *Cross Fusion Strike* with the **same exact Benched donor's printed Max Miracle**. In [the preregistered 32-attempt experiment](../registrations/agent13-rank5-selfcopy-maxmiracle-prospective-20261106.json), all 16 A/B pairs retained exactly matching **source and candidate physical initial deals, actual first-player assignment, and original fixed 60-card registrations**. Two historical-canary pairs had different genuine Store root histories. They collectively replaced **five** genuine control `Mew VMAX FST / Cross Fusion Strike` copy choices with **five** owner-selected `Mew VMAX FST / Max Miracle` copies and real physical effects. There was **no root difference in any of eight fresh-seed candidate contexts**; the treatment did not encounter this choice there.

**One historical champion-reference context:** at source global turn 9 and source AttackAction ordinal **55**, original rank5 source seat0 chose the copy at `ChooseAttackPrompt` ordinal **56**. The control chose the same Mew VMAX donor's *Cross Fusion Strike*, leaving opposing Lillie's Clefairy ex at **0 damage**. Treatment selected its *Max Miracle*, bringing the **same original opponent Active from 0 to 130 damage**. Opponent's actual next turn began with a **Psychic Energy attachment** at ordinal 60. Both completed with the same native winner (seat1) and **91 roots / 16 turns**. No Prize was awarded for this changed attack.

**One historical New Moon Lockbreaker v1 context:** source seat0, going second, made the same source-root choice change for **four** global source turns **9, 11, 13 and 15**. The control's four source self-copies each caused **zero public Active damage** and no Prize. The treatment physically dealt printed 130 per copied *Max Miracle*: 0→130 damage to Squawkabilly ex on turn9; its next attack at turn11 knocked out Squawkabilly ex and moved original-source remaining Prizes from **6 to 4**, with a real opponent promotion to Trevenant & Dusknoir-GX; turns13/15 placed **130 and another 130** on that promoted Pokémon. Actual opponent next-root actions were T10 playing Trevenant & Dusknoir-GX, T12 playing Solrock, T14 playing Latias ex, and T16 passing. The frozen native policy eventually gave the original rank5 source seat0 the same native winner in both arms, with treatment finishing at **119 roots / 21 turns**, versus control **149 roots / 29 turns**. These horizon changes are post-treatment developments, not a certified change in competitive win probability.

Both contexts have genuine same-game `AttackAction` → native `ChooseAttackPrompt` → source-owned `ResolvePromptAction` → public board/Prize settlement → opponent root custody. The **first actual root divergence** is exactly the printed donor selection: ordinal 56 in the champion context and ordinal 55 in the New Moon context. All earlier public physical root histories match. This result is a useful **source-player policy competence regression canary**, not evidence favoring one 60-card contender.

## Independent post-archive audit and measurement correction

The original native runner's **convenience-only diagnostics** mistakenly inspected `row.policyAudit.detailedComponentAudits.chooseAttack` instead of the actual `row.actorOnlyDecisionCoverage.detailedComponentAudits.chooseAttack`. It therefore reported `sourceSelfCopySelections:[0,0]` and `sourceMaxMiracleSelections:[0,0]` despite the genuine choices being retained in each full raw row. It also compared Prize arrays by JavaScript object identity rather than by value, incorrectly counting every settled attack as a Prize change. **Do not use those two convenience fields in the uploaded v1 native summary.** These bugs did not affect a single Store action or any native matchup.

I corrected future-run diagnostics in the runner and wrote the independent read-only post-archive parser `simulation/evaluation/agent13-rank5-selfcopy-archive-audit.cjs`, which joins the actual `ResolvePromptAction.attackChoice`, original actor-only selection, initiating source `AttackAction`, same-root public board transition, Prize count **by physical source seat**, and opponent's next actual root. Source-positive root joins require `settledPromptChain:true` and no cross-reset settlement. Five pure regression tests plus the separate actor-choice tests passed via [existing manual copied-attack workflow run **42227603829**](https://github.com/FlareZ123/experiment-01/actions/runs/42227603829), SUCCESS. The corrected counts in this report were independently computed from the preserved 40 MB original archive, with no retrospective deletion or invented replay.
