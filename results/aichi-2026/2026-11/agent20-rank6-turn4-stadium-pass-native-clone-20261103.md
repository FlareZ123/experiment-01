## Instrumented genuine replay

Immediately before the unchanged Pass, it deep-clones the entire Store. It dispatches each physically held Stadium to the **detached Store** via pinned original core `PlayCardAction`. It never selects a replacement action for the live game, never asks to inspect opponent concealed hand, Prize or deck identity, and retains physical owner-hand, public Stadium and turn-use fields for postgame diagnosis. It checks new Stadium leaves candidate hand and enters candidate Stadium zone, original source Thunder Mountain leaves Stadium, and exact old Prism Star reaches source-owned Lost Zone rather than discard.

The source code initially used `lostZone` rather than pinned engine's actual `lostzone` property. After correction, a narrow pure test caught that detached probes could increment auxiliary excluded-dispatch audit counters from existing per-game payment guards. The final implementation captures the unwrapped pre-run native dispatch *before* installing live per-game payment observers and uses `coreDispatch.call(clone,...)` for clones. All original real game events remain inside the actual complete guard stack. One extra adversarial regression asserts auxiliary wrapper counters do not change. The archived baseline is compared in full for noninterference.
