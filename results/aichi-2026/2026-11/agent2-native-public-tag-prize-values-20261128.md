# Pinned Twinleaf public Pokémon categories disappear in generic actor observations; TAG TEAM/Mega 3-Prize valuation rescued

**Agent 2 — 2026-11-28 14:07 UTC.** Pinned native source inspection, actor-only mitigation, source printing fallback, synthetic validation. No Store game, CI or qualified Aichi matchup.

## Actual source mismatch, not an uncertain tag convention

Pinned Twinleaf `a9905a76a6c4103ba4b6cb9a49e86bad795c5c05` defines `PokemonCard` in `ptcg-server/src/game/store/card/pokemon-card.ts`. It has `stage`, `cardType`, `attacks`, `powers`, etc, **but no `subtypes` field**. Its `Card` base class exposes permanent printed `tags` through a public getter, with backing `_tags`. Pinned `card-types.ts` lists `CardTag.POKEMON_VMAX='VMAX'`, `CardTag.POKEMON_VSTAR='VSTAR'`, `CardTag.POKEMON_SV_MEGA='Mega ex'`, `CardTag.TAG_TEAM='Tag Team'`, `CardTag.POKEMON_ex='ex'`, etc. These printed tags encode explicit Prize liabilities and many other relevant tactical categories.

Research generic actor boundary `simulation/twinleaf/actor-observation-contract.cjs` instead emits `printed.subtypes:[...(pokemon.subtypes??[])]`. For ordinary pinned card instances that have tags but no fabricated subtypes, it emits **an empty category array**. This is a source-level interface mismatch: a synthetic policy test that assigns `printed.subtypes:['MEGA','ex']` does not reproduce the real category state. This gap affects *every policy* relying on printed subtypes, not just Regidrago.

## Immediate rank27 runtime-safe Prize evaluation repair

The rank27 Regidrago opponent policy `publicPrizeValue` determines whether a damaged opponent Bench target awards enough Prizes for a terminal Guzma/Prime Catcher plus Phantom Dive line. Previous 3-Prize checks recognized subtype=MEGA/TAG TEAM but **not actual native subtype-empty field**, and public name regex did not recognize **Mega Kangaskhan ex MEG** or **Trevenant & Dusknoir-GX SMP**. Both were wrongly treated as two-Prize targets. These are source-attested Aichi rank18 Mega Kangaskhan and rank1 Trevenant & Dusknoir.

Updated `simulation/evaluation/2026-11/agent2-rank27-regidrago-opponent-policy.cjs`, [0554f33](https://github.com/FlareZ123/experiment-01/commit/0554f330445e3b8e2baab464d9d9ca226c715d9f): precise public printing fallback for **Mega ex MEG/PFL/ASC** and **ampersand TAG TEAM-GX CEC/TEU/SMP/UNM/UNB/HIF**, alongside existing VMAX/VUNION and real subtype checks. This is intentionally scoped to the published field printing families; it does not silently claim that arbitrary unknown labels are 3-Prize. Regression [a044eba](https://github.com/FlareZ123/experiment-01/commit/a044ebaa161b7743f513f40bdcb37659dc486d16) gives 14 actual source-style empty-subtype printing classifications and both-seat terminal Prime Catcher line: **34/34 rank27 synthetic groups, 464 assertions pass**.

## General research-side owner/public-safe opt-in category projection

Added `simulation/evaluation/2026-11/agent2-native-public-pokemon-tag-projection.cjs` [3f21c42](https://github.com/FlareZ123/experiment-01/commit/3f21c42582dd760f3eae3fecfa8b850dce68a6e0). Its `enrichNativePublicPokemonTags({state,observation,actorSeat,enginePin})` is a post-actor-observation **pure detached object transformer**. It checks the exact native pin, face-up phase, physical actor seat, public board slot/Bench counts and each exact visible printing identity against `slot.getPokemonCard()`. It reads **only the already face-up own and opponent Active/Bench `Card.tags`**, never deck/hand/Prize cards, then attaches normalized `VMAX`, `VSTAR`, `V-UNION`, `TAG TEAM`, `MEGA` (new Mega ex), `GX`, `ex`, `V`, `EX`, etc to detached `printed.subtypes` values without mutating the frozen source observation. The old subtype list and other public metadata survive. Native Card.tags getter returns printed tags, not transient runtime tags, which also prevents confusing temporary tag effects with printed card identity.

Tests `tests/2026-11/agent2-native-public-pokemon-tag-projection.test.cjs` [59ce036](https://github.com/FlareZ123/experiment-01/commit/59ce036ee0c9512af27fae64247fab0460967de8): **6/6 V8 in-process test groups, 52 assertions**, both physical seats, native-shaped Pokémon with no `subtypes`, public VSTAR/VMAX/Mega/Tag Team recovery, frozen original, Proxy private zones that throw if accessed, wrong engine pin, wrong card identity, wrong actor seat, mismatched Bench and concealed setup rejection.

**Evidence scope:** This is a pinned-source API inconsistency and synthetic board-only regression, not a compiled native Store witness. The public tag enrichment is intentionally **opt-in**, does not modify the frozen generic actor observation, upstream Twinleaf, host dispatch or existing benchmark runner.
