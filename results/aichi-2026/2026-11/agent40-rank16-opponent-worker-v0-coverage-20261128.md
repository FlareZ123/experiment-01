## 28 November 03:59 UTC incremental decision repairs

1. **Float Stone native target prompt:** The root already prefers attaching Float Stone to an Active Trubbish to pivot into zero-Energy Budew; the actual following `ChoosePokemonPrompt` previously scored only Garbodor, so it would attach to the Bench and strand Trubbish. Now the target prompt uses the post-play board rather than the no-longer-held Float Stone. It selects the Active Trubbish when a payable mobility bottleneck exists, preserves an equipped Garbodor option when Block or a used Tool prevents the pivot, refuses Jamming Tower, and accepts unevolved Trubbish as a future Garbotoxin carrier. Both-seat synthetic prompt regressions cover the cases; no same-Store native replay has been authorized.
2. **Cross-lock ability matrix:** Snorlax PGO55 Block, Wobbuffet PHF36 Bide Barricade and Iron Thorns ex TWM77 Initialization now consult the same explicitly observed suppression, live Garbotoxin, Stealthy Hood and Jamming Tower fallback used for Vileplume/Stoutland. New tests verify all four states in both seats. Full engine ordering has not been replayed.
