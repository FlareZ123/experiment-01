- Rank6 `attack-settlement` misrepresented as global-turn-1 pressure, an absent native printed-Power block, missing source Active continuity or reply/return, and an attack root used in place of the genuine source first-turn Pass boundary.
- Rank11 absence of the observed source Tool Garbodor native block, or a root action that is something other than paid `Boost Shake` when a full Store ledger is provided.

## Native producer and acceptance limitations

**This is a validation of the contract and tests, not of a live source-first lock.** The classifier still consumes producer-populated `rank6PassivePressure` and `garbotoxinWindowAudit`. It cannot independently prove the telemetry came from an actual pinned Store without separately preserved engine transcript, registration, known physical-deal fingerprint and native root attestation. At rank11, the existing observer's generic `candidateGenericAbilityBlocked` is only provisional when no explicitly observed New Moon Power exists, because a generic PowerEffect can misrepresent printed exemptions. This must be replaced with actor-native per-printed-Power checks before a general competitive qualification.

Even a genuine blocked printed Ability can fail to prevent any tactically useful action, for example when the candidate lacks a payable attack, a hand trigger, or a relevant Weakness interaction. The decision intake must preserve `no-applicable-target-observed` cases unfiltered and separately model meaningful missed opportunities.

Full-deck quality and paper Expanded print legality, realistic 25-minute clock, actor-information-safe combined policies, all attempts and both physical start orders, and exact 32/32 source field remain independent unresolved qualification dimensions. The standing project count is **29/32 exact Top32 source lists, zero competitive-qualified games, 99.5% unproven**.
