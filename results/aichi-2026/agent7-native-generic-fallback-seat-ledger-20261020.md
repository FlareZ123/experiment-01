## Observer contract

The observer wraps the *original* `SimpleTacticsAi.decodeNextAction` outside all canonical actor-only interceptors. When an inner interceptor successfully selects an action, it bypasses the original decoder. If every interceptor delegates, the original decoder is invoked and counted only if its `state` argument is the same object as the authentic current `Store.state` and the bot's client ID maps to a physical actor seat. The observer records:

- physical seat (0 or 1), actual turn and phase;
- whether the generic call concerns that actor's pending prompt, a foreign prompt, a root/setup context, or an out-of-turn context;
- native pending prompt class and returned native action class;
- a bounded series of 96 metadata-only records per genuine Store game.

It does **not** retain hand, deck, Prize, or concealed opponent cards, or the contents of prompted card selections. It returns exactly the original decoder result and restores all prototype method descriptors. Its audit's `fullyActorOnly` / competitive qualification remains false. Counted decoder *invocations* are not proved unique choices, resolved prompt actions, native success, opponent competency, or clock-qualified turns.

## Next integrated experiment and limits

The remaining fully native original decoder exposure in these fixtures is entirely on owner prompts. The next useful *common-policy* advance is to replace strategically consequential prompt calls with owner-information-only, typed, legally validated native decisions and to rerun the full canonical source/candidate paired controls. Agent 41 is already integrating a ChooseCardsPrompt owner-only slice; avoid building a competing independent runner or overriding that work. In particular, existing `ChooseCardsPrompt` (43 calls) and `OrderCardsPrompt` (21 calls) should be characterized by the actual owner prompt semantics before being replaced by a default answer. The less frequent `ChoosePrizePrompt`/modal categories may be similarly important. Wait/display prompts should be audited rather than blindly classified as tactical decisions.

The root adapter still has limited card-play coverage and scripted source-first pressure is not a competent independently responding opponent. A fully qualified game needs a complete, common, two-sided, actor-safe policy, authentic source pressure, tested continuation, competitive clock/rules fidelity, and an independently registered full-field comparison. The present result changes **which bottleneck is observable**; it does not nominate a winning 60-card deck.
