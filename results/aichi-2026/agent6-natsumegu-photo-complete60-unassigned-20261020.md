## Reproducible source-image relation, not intuitive adjacency

The [audited script](../../scripts/aichi_natsumegu_gallery_link.py) validates each original archived image's SHA-256, dimensions and PNG pixels, then directly compares the original tweet's card-grid inset `[510,920,1030,1487]` with the distinct standalone photographed grid. OpenCV ORB with 4,000 descriptors, Hamming distance, 0.75 ratio filter and 4-pixel RANSAC homography gives:

- **866** strong feature matches.
- **820** geometrically consistent matches.
- **94.6882%** homography inlier fraction, at OpenCV **4.14.0** in compiled CI.

This independently establishes that both images contain the **same original card grid**, rather than assuming consecutive gallery images belong together. It does not establish an official registration, the legal name of the author or printed card identity. The [offline synthetic regression tests](../../tests/test_aichi_natsumegu_gallery_link.py) reject corrupted original hashes, wrong dimensions and changed badge counts.

The optional `natsumegu_visual60_relation=true` flag reuses the *existing manual-only* [gallery provenance workflow](../../.github/workflows/aichi-gallery-provenance.yml), without any push-trigger CI. [Compiled manual run 39467320444](https://github.com/FlareZ123/experiment-01/actions/runs/39467320444) **PASSED** all tests and actual live source comparison at commit `c1d59d3771a73ff7281a4b30a1d17ae7f7a27685`. Its [machine-readable artifact 12286220105](https://github.com/FlareZ123/experiment-01/actions/runs/39467320444/artifacts/12286220105) was downloaded and independently SHA-256 checked: ZIP `4dc29166985272e67e66210e922ae57142c2d8a9ebcbd0e2d4670b8befe715ff` equals Github artifact digest.

## Why the official source manifest remains unchanged

The poster reports **Swiss qualifier position 16**, whereas the [published Limitless final rank 16](https://limitlesstcg.com/tournaments/566) is **Takumi Matsumoto, Absol/Garbodor**, a different archetype from the poster's Regidrago. This is a concrete counterexample to naive numeric equivalence between self-reported Swiss rank and the published final standings rank. The social handle and physical event badge do not establish the poster's official registered civil name.

The absent official Regidrago rank **23** is **Yuki Ueno**, while missing rank **28** is **Jo Kato**. No direct source ties **Natsumegu** to either official entrant, and the uploaded picture's possible resemblance to any other Regidrago roster would be insufficient identity evidence. A specific event registration, independently authenticated bracket mapping, actual official name or contemporaneous official deck code is still necessary.

**Evidence status:** A second completely photographed Regidrago 60 exists in source, with post-to-photo attribution supported by strong image geometry and every quantity badge transcribed. The **official rank 23/25/28 60s remain unverified**, and the exact opponent source count remains **29/32**, with **zero** competitive-qualified games and no supported 99.5% single-deck claim.
