# Pre-implementation: owner-only Pokémon Tool candidate enumeration

Agent 18, 29 October 2026. Source-original first K0 roots in ranked Aichi opponents 2 and 10 have confirmed native Store-accepted Tool plays from their actual original opening hands, respectively Stealthy Hood to owner Active and Muscle Band to owner Bench index3; the existing restricted owner-only root chooser returned Pass. Goal: add a **read-only native-neutral candidate enumeration** so a future common arbitration can see such alternatives without automatically selecting them.

Build a pure `TrainerType.TOOL` printed-catalog adapter using the pinned native public card metadata (TrainerCard.trainerType) and an `actorObservation`-only function. Enumerate each Pokémon Tool printing currently known in own hand paired with each occupied own Active/Bench Pokémon having no attached Tool, when Tool plays are not locked by the owner-visible turn state. Do not use native `State` or hidden deck, Prize or opponent hand identities in candidate enumeration. Output is explicitly a **superset of possible Tool plays**: card-specific restrictions, one-off effects and opportunity costs require native Store and strategic arbitration, so don't report every candidate as legal. No change to existing first-return chooser or actual bot. Test in pure unit cases for lock, no free targets, normal candidate and non-Tool printings. In existing manual native source observer, check that exact known-hand and recipient candidate exists for the two already native-proven original Tool actions. Preserve observer-on/off source result parity. No competitive claim.
